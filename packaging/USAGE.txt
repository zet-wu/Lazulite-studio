Lazulite Studio 本地打包版

一、解压与启动
1. 下载对应系统的 7z 包，使用支持 7z 的工具完整解压到任意目录（不要直接在压缩包内运行）。
   如果是分卷包，请将全部 .7z.001、.7z.002 等文件放在同一文件夹，从 .7z.001 开始解压。
2. 双击启动程序：
   - Windows：start.exe
   - macOS：start.command
3. 保持终端窗口开启，服务就绪后会自动打开浏览器；也可手动访问 http://127.0.0.1:15173 。在终端按 Ctrl+C 停止服务。

二、使用说明
- 程序已内置完整运行环境、内置词典和默认 Demucs 人声分离模型，无需额外安装 Python、Node.js、FFmpeg 或 CUDA Toolkit。
- 下载可选模型和在线搜索歌词需要联网；模型下载完成后，人声分离与自动对齐均可离线运行。
- Windows CUDA 版需要兼容的 NVIDIA 显卡驱动；如 GPU 不可用，可在设置中改选 CPU。
- macOS 版未做开发者签名与公证，首次打开如遇系统拦截，请在「系统设置 → 隐私与安全性」中允许运行。
- 项目数据与设置保存在程序目录下的 data/，运行日志保存在 logs/。

三、安装可选模型
以下目录均相对于解压后的程序根目录。

1. 对齐模型（NextFire / MMS_FA）
- 自动下载：Windows 双击 download-align-models.cmd，macOS 双击 download-align-models.command，按菜单选择模型即可，下载完成后位于 models/。
- 手动安装：下载对应 Release 中的 NextFire-karaoke-ja-Latn.zip 或 MMS_FA.zip，保留压缩包内的模型目录直接解压到 models/，形成：
  models/NextFire-karaoke-ja-Latn/
  models/MMS_FA/
- 安装后在设置「模型与计算 → 对齐模型管理」中点击刷新即可选用。MMS_FA 通用模型在部分歌曲上结束时间可能偏早，建议配合「智能延长结束时间」选项使用。

2. BS Karaoke 主唱分离模型
- 默认已内置 Demucs（位于 vocal-models/demucs/）。如需更好的和声与背景人声分离效果，可额外安装 BS Karaoke（较耗时，不建议仅用 CPU 推理；macOS 版使用 CPU）。
- 自动下载：Windows 双击 download-vocal-models.cmd，macOS 双击 download-vocal-models.command，输入 Y 开始下载，完成后位于 vocal-models/bs-karaoke/。
- 手动安装：下载 bs-karaoke.zip，保留压缩包内的 bs-karaoke/ 目录解压到 vocal-models/，形成：
  vocal-models/bs-karaoke/bs_roformer_karaoke_frazer_becruily.ckpt
  vocal-models/bs-karaoke/config_karaoke_frazer_becruily.yaml
- 安装后在设置「模型与计算 → 人声分离模型管理」中刷新并手动切换模型。切换模型只影响后续新分离，已有音频可继续复用，如需按新模型重算请使用「重新分离」。

四、下载脚本注意事项
- 若目标模型目录已存在且非空，脚本会自动跳过；若目录内容损坏，请先手动移走该目录再重试。
- 下载过程中按 Ctrl+C 取消或失败时，会自动清理 tmp/ 中的临时文件，不影响已安装的模型。
- 如果在设置中修改过自定义模型总目录，请恢复默认，或将下载后的模型子目录移入你的自定义目录后再刷新。
