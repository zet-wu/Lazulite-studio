# Lazulite Studio 简易教程

## 歌词获取
Lazulite Studio 支持从网易、QQ、酷狗、AMLL TTML DB 四个在线源搜索和获取歌词，并能保留其提供的词级时间和音译/翻译行。初始化项目或者首次上传音频时，会从歌曲元数据中获取标题、艺术家、专辑字段填入搜索框，标题若缺失则使用去后缀的文件名，后续也可手动修改。搜索时仅使用标题作为关键词，艺术家和专辑参与结果匹配打分。

“关联歌曲ID”可向 TTML 元数据按 [AMLL TTML DB](https://github.com/amll-dev/amll-ttml-db) 写入对应网络歌曲的 ID，方便向其投稿。

## 音频分析

必须先分离人声，才能进行自动对齐。人声分离后，通过声学分析算法为歌曲划分为若干人声片段（界面显示为“片段”）。对齐时，使用所有人声片段拼接后送入对齐模型，因此在对齐前，可以人工删除、增加、调整片段来修正声学分析的结果或降低干扰（但一般情况下不需要自己调），在编辑界面也可以指定某几行不参与对齐。对齐的读音使用正文假名，以及有注音正文的假名注音，缺失注音的汉字会被跳过，因此需要保证注音完整且无误。**注意，不使用音译轨道，也不支持罗马字注音，没有注音的英文会原样送入对齐模型。**

自动对齐的三个“实验性对齐选项”借鉴自 [MiliKara](https://github.com/BilyHurington/MiliKara) 的对齐算法，注意，笔者在有限样本上的消融测试显示这几个选项对实际对齐结果影响甚微，有时还可能有负面影响，请自行评估是否打开。

## 编辑

编辑界面支持任意单元的单选、多选、拖动，右键菜单支持批量合并（需要选中单元连续）、批量删除等操作。

### 歌手（演唱者）管理
位于编辑界面上方工具栏的“歌词设置”展开菜单，TTML 的歌词模型采用稳定 ID （如 `v1`，`v2`）管理，并可有自定义的 `name` （名称）字段，Lazulite Studio 在相关设置中优先展示歌手名称，未填写时采用歌手 ID。需要指定词级歌手时，必须在右上角设置“AMLL 兼容设置”中关闭“禁用词级歌手”（默认开启）

### 生成日文罗马音音译
从已有的注音（Ruby）生成音译轨道，预览框可直接修改生成结果。会默认高亮 `は` `へ` `を` 这三个有特殊读法的假名的生成结果以供确认，可在右上角设置“音译生成假名高亮”配置需要高亮的假名。

### 从音译生成注音
从带词级时间的音译轨道，通过时间重叠的匹配，为对应的正文目标词生成假名注音，生成结果与正文相同时，该项跳过生成，未能匹配到唯一最佳正文词的音译单元会高亮提示用户手动选择目标或者跳过生成。

### 生成日文注音
不依赖于行级轨道，使用词库为正文注音，会自动拆分可分的正文词，预览框可直接修改生成结果。

## 打轴
Lazulite Studio 的打轴交互基本参考了 [AMLL TTML Tool](https://github.com/amll-dev/amll-ttml-tool)，界面则参考了 [StrangeUtaGame](https://github.com/karaoke-studio/StrangeUtaGame)，当前打轴点所在单元在画布上会高亮显示。同时，在打轴界面通过双击打开输入框也可以编辑正文、注音，并有与编辑界面基本相同功能的右键菜单。
默认快捷键：
- 起始轴：`s`，将当前时间填入到当前打轴点的起始时间中，打轴点不前进
- 连续轴：`d`，将当前时间填入到当前打轴点的结束时间，然后，若有空拍，消耗一个空拍，若已无空拍，则将当前时间填入下一个打轴点的起始时间，打轴点前进一个单元
- 结束轴：`f`，将当前时间填入到当前打轴点的结束时间，打轴点前进一个单元，无视空拍

可以通过右上角的设置“快捷键设置”查看和修改快捷键

打轴界面上方工具栏可以切换“连续”/“本行”模式，“连续”即整首歌从头打到尾，“本行”则在每行最后一个单元停止，使用连续轴/结束轴时不自动前进到下一行，需手动点击切换到下一行，适合配合“A/B 区段循环”使用。

## 卡拉 OK 导出
默认会将正文行和背景行分为两个分组，导出单独文件，也可在卡拉 OK 界面的“分组管理”新增、删除分组，并在行的右侧属性栏中分配分组。

翻译和音译的每一个轨道都将作为单独文件导出，在“导出 NicoKara”窗口中可选择具体导出的分组。

歌手标记的实现参考了 [StrangeUtaGame](https://github.com/karaoke-studio/StrangeUtaGame) 的“分色助手”，Lazulite Studio 直接使用 TTML 的歌手属性确定导出时歌手标记的插入位置。

卡拉 OK 界面可以在正文每一行前，以及行内词之间存在时间空白处、词内注音之间存在时间空白处插入导唱符，导唱符只在“导出 NicoKara”中使用，不进入 TTML 文件。
