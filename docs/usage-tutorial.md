# Lazulite Studio 使用教程

Lazulite Studio 围绕 TTML2 歌词模型设计，将在线/本地歌词获取、自动分词与注音、人声分离与自动对齐、手动打轴、时间轴声谱微调，以及面向播放器与卡拉 OK 工具（如 Lin-K、NicoKaraMaker 3、AMLL）的多格式导出整合在同一套工作台中。

既可以通过工作台界面以**人工与半自动化**方式制作和精修歌词，也可以通过内置的 **MCP 服务接入外部 AI Agent**，由 AI 自动驱动整套工具链完成全流程制作。

## 人工与半自动化制作流程

在工作台界面中操作时，如果是第一次使用 Lazulite Studio 制作逐字/逐音歌词，推荐按以下步骤进行：

1. **新建项目并获取歌词**：在项目列表点击“新建项目”上传音频（或视频，系统会自动提取音轨），进入**歌词获取**页搜索在线歌词或导入本地文本，确认元数据后导入。
2. **补全分词与注音**：切换到**编辑**页。日语歌曲使用“智能日文注音”自动拆分汉字词并标注假名；中文、粤语或方言歌曲使用“词典注音”标注拼音并核对多音字候选。若需要罗马字或粤拼等音译行，可在注音核对完成后一键生成音译轨道。
3. **自动对齐生成初轴**：点击**音频处理**页右上角的“自动对齐”（若尚未分离人声，会自动先执行人声分离与片段切分）。日语歌优先选用 `NextFire-karaoke-ja-Latn`；其他语种或方言选用 `MMS_FA` 并开启**智能延长结束时间**。
4. **局部重算与精修**：对照底部或音频处理页的**声谱图**与**空隙轨**检查时间轴。若日语歌首轮对齐后个别长音或连续同元音行出现挤缩，可选中该行右键执行**局部自动对齐**，换用 `MMS_FA + 智能延长结束时间` 重算；细微偏差可直接在时间轴上拖动边界，或切到**打轴**页配合“本行”模式与回听校准重新点按。
5. **导出或打包**：需要制作卡拉 OK 视频时，在**卡拉 OK**页插入导唱符、配置好分组和 SUG 歌手映射，随后到**文件打包**页导出 SUG 项目供 Lin-K 使用；若用于音乐播放器，可直接导出 TTML / LRC，或通过“音乐文件嵌入”将歌词直接写入 M4A / MP3 / FLAC 文件。

### 分篇界面教程目录

以下四个专题章节详细说明工作台各个界面的功能与操作细节，可按顺序阅读或直接跳转到对应部分：

1. **[歌词获取、编辑与自动注音](tutorials/1-lyrics-and-editing.md)**
   - 项目创建与工程归档（`.lazp`）
   - 在线四源搜索、音频内嵌歌词读取与本地歌词（含 SUG 0.3.0）导入
   - 简洁编辑与高级编辑视图、选区与拆分（`K`）/ 合并（`M`）操作
   - 歌词元数据、歌手管理（虚拟角色与声优关联、词级歌手）与翻译/音译轨道管理
   - 智能日文注音（含数字与量词）、词典注音（普通话/粤拼/潮州话与多音字候选）、罗马字音译生成、从音译反推注音、简繁/中日汉字转换与批处理工具
2. **[音频处理与自动对齐](tutorials/2-audio-and-alignment.md)**
   - 人声分离模型选择（快速的 `Demucs` 与剥离和声的 `BS Karaoke`）、外部人声上传与偏移估算
   - 人声片段（`core`）的作用、分配与手动调整
   - 对齐模型（`NextFire-karaoke-ja-Latn` 与通用 `MMS_FA`）配置与管理
   - [Studio 对齐流程及建议](tutorials/2-audio-and-alignment.md#studio-对齐流程及建议)：前处理（拉丁归一化、去除调号数字）与后处理（智能延长结束时间、合并行内短空隙）
   - 局部自动对齐与**跨模型异常行重算**技巧
3. **[手动打轴与时间轴微调](tutorials/3-sync-and-timeline.md)**
   - StrangeUtaGame 打轴风格（默认：单键配合起止点、词内节奏点与终止点）与 AMLL 打轴风格（起始轴 `S`、连续轴 `D`、结束轴 `F`）
   - “连续”与“本行”模式、A/B 区段循环、变速播放（`Q`/`E`）与定位回听校准
   - 时间轴与声谱图微调：暂存区拖入分配与拖回清空、相邻贴合边界联动拖动、滚轮缩放与平移
4. **[卡拉 OK、预览与导出打包](tutorials/4-karaoke-and-export.md)**
   - 卡拉 OK 导唱符插入与输出分组管理
   - SUG 0.3.0 项目导出与 SUG 歌手管理（面向现代化卡拉 OK 制作工具 [Lin-K](https://github.com/karaoke-studio/karaoke-studio) 的分轨歌手映射）
   - NicoKaraMaker 3 导出与歌手标记
   - AMLL 实时预览与兼容设置
   - 歌词文件导出（实时校验与分轨全局偏移）及音乐文件内嵌打包（MP4/M4A STPP、MP3 USLT、FLAC LYRICS）

## 基于 MCP 的 AI 全自动化流程

除了在界面中手动或半自动操作外，Lazulite Studio 还内置了符合 [Model Context Protocol (MCP)](https://modelcontextprotocol.io/) 标准的语义工具服务（共包含 41 个工具，涵盖项目与歌词读取、分词与自动注音、人声分离、全局与局部自动对齐、异常行筛查、局部声谱图生成与 30 秒以内音频片段听审）。其内置的 Prompt 能够有效地指导 AI Agent 完成歌词导入、分词注音、自动对齐、异常行重算和精调的全流程，实现全自动化地产出高质量逐字歌词。

如果你使用 Claude Desktop、Cursor 或其他支持 MCP 的 AI 客户端，可以让 AI 助手直接连接本地运行中的 Studio 自动执行上述工作流，或在人工制作过程中协助检查读音与修补时间轴：
- **Streamable HTTP 连接（推荐）**：本地打包版启动后，默认在回环地址同端口提供 MCP 端点 `http://127.0.0.1:15173/mcp`（仅接受本机连接）。
- **`stdio` 命令行连接**：也可在客户端配置中直接调用包内自带的精简 Node 运行时启动：
  - Windows：`runtime\node\node.exe app\mcp\server.mjs --transport stdio --data-dir data`
  - macOS：`runtime/node/node app/mcp/server.mjs --transport stdio --data-dir data`

外部 AI 工具通过 MCP 提交的任何修改都会实时同步到浏览器工作台中，并同样支持在工作台里按 `Ctrl + Z` 撤销。
