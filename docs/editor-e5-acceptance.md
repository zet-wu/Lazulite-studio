# E5 打轴模式与播放控制验收

日期：2026-09-26。结论：**E5 连续打轴与共用播放器已实施，并通过打轴、音频和浏览器回归验证**。可编辑波形、频谱与 BPM 属于 E6。

## 可操作结果

- 项目页可在编辑与打轴模式间切换，项目音频播放器保持在页面底部。打轴游标按主唱行的词序前进；有 Ruby 时依次经过每个读音单元，跳过背景行和标为“跳过打轴”的行。起始轴设当前单元开始，连续轴在一次事务中结束当前单元并开始下一单元，结束轴只关闭当前单元。Ruby 的父词和行时间随读音更新；一次落点对应一次撤销。
- 支持单元与行前后导航、回听定位、前后短片段试听、输入偏移与当前起点校准。项目页选中词或 Ruby 后可以使用播放器的当前单元循环。起始/连续/结束轴及前后导航均有触控按钮和可修改的按键速查；重复键、IME 输入、文本框内按键与弹窗按键不会触发全局打轴。
- 词的空拍数和行的跳过打轴标记可编辑。空拍数先消耗连续轴次数，再结束当前词。两项设置保存在 Studio 草稿 TTML，最终 TTML 不携带编辑辅助标记。音频时钟只由 `MediaTransport` 持有；切模式和撤销不会 seek 或重启音频。

## 边界

- Ruby 与词时间可在画布字段精修。波形边界拖动、吸附、频谱和 BPM 定位由 E6 实现。
- 演示项目的音频 URL 未提供真实媒体；浏览器的播放打轴测试注入仓库内的合成 WAV。实际项目仍使用服务端音频与 waveform 接口。
