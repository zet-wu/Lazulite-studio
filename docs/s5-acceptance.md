# S5 日语 Ruby 工作流验收

日期：2026-09-12。S5 功能闭环验收通过；细粒度读音时间与模型质量边界如下。

## 实现范围

- `RubySpan` 以稳定 ID、正文 Unicode code point 半开范围和整体 reading 表达，不建立逐字符假名映射。支持新增、修改、删除、撤销、重做及 TTML2 `tts:ruby` 保真写回。
- 可理解的 Ruby 行仍可修改正文与行级时间；正文只有在现有范围与 base 继续匹配时才能提交，不安全的移动不会被静默重映射。复杂 inline、未知 namespace 或未知属性保持只读。
- `reading` 使用现有持久任务协议，从指定不可变 revision 投影纯正文。SudachiPy 返回整词候选；项目词典命中优先，结果携带来源、复核提示及 revision/asset 绑定，只能人工应用。
- 项目读音词典支持列出、新增、完整替换和删除。词典写入不修改 TTML、Ruby 或审核状态，之后重新生成候选才会使用新值。
- 工作台右侧“注音”通过浏览器文本选择建立整体范围，显式完成 UTF-16 到 code point 的转换；现有 Ruby 就地预览和编辑。左侧“词典”维持紧凑列表，桌面三栏与窄屏面板沿用既有结构。保存后的读音确认复用行审核及其 CAS/内容指纹，不增加第二套确认状态服务。

- 前端单元/集成测试：44 项通过，包含 Ruby 往返与稳定 ID、撤销和确认失效、复杂结构只读、UTF-16 选择映射、候选过期和人工应用。

## 边界

S5 只提供读音候选，不将 Sudachi 分词结果宣称为歌词特有读音真值；所有候选仍需人工应用和确认。当前只使用一套 SudachiPy 后端，因此 `needs_review` 不代表统计置信度。用户词典按项目隔离且精确复用词面，不做全局共享或自动批量改稿。

本阶段没有实现 mora/phoneme 单元、Ruby 时间、forced alignment、复杂 group 或 stpp 发布，这些分别属于 S6/S7。未执行真实 J-pop 读音质量 benchmark，也未修改并列 Lazulite 引擎源码。
