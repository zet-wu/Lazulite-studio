# E2 参考布局与直接编辑验收

日期：2026-09-25。结论：**E2 退出条件通过**。验收对象为本地 `/editor` 与项目工作区共用的 `EditorWorkspace`；参考基线和 E0–E1 记录见 [对齐矩阵](editor-parity.md)。E3–E7 的分词、完整 Ruby 工作流、打轴、时间轴、预览及多格式导入导出不计入本次 E2 结论。

## 发现与收尾

| 复查发现 | 本阶段处理 | 行为证据 |
| --- | --- | --- |
| 全量挂载歌词行，长文档滚动和变高行不成立 | 使用 TanStack Virtual 按行实测高度渲染；大纲定位和跨屏词导航滚动到目标 | 2,000 行、20,000 词浏览器用例；同时挂载行少于 40，末行可定位 |
| 虚拟列表滚动可能卸载正在输入的行 | 焦点所在行留在虚拟范围，失焦提交后再释放 | 在首行输入草稿、滚动至第 2,000 行、返回和撤销的浏览器用例 |
| 大纲不能排序 | 在大纲中加入行上移/下移，背景随主行移动 | 大纲排序后一次撤销，Ruby 仍在原行 |
| 单击词会直接修改，缺少双击编辑 | 单击选择、双击或 F2/Enter 进入编辑；Escape 取消；输入结束提交 | 本地及项目编辑、撤销用例；IME 合成期 Escape 不退出 |
| 词选择只限单行 | Ctrl/Cmd 追加和 Shift 范围覆盖跨行词；跨行剪切、复制及粘贴保持词时间和 Ruby | 跨行四词剪贴、粘贴、时间扩展及撤销用例 |
| 多行属性没有混合值和批量设置；对唱入口缺失 | 歌手/对唱显示混合值，批量改动合成一次命令 | 双行歌手与对唱改动、一次撤销用例 |
| 触屏无法使用拖动手柄 | 行/词手柄处理触屏指针拖动；桌面仍支持拖动与 Ctrl 拖动复制 | 390px 触屏拖词及撤销用例；桌面行词拖动/复制用例 |
| 时间输入格式错误会在事件中抛出异常 | 字段旁报告错误，保留输入继续修正 | 非法秒数、纠正及无多余历史用例 |

## E2 条目

| 计划条目 | 结果 |
| --- | --- |
| 项目连接层与共用工作区；菜单、Ribbon、列表、行、词、选择交互层 | 通过。两个入口共用 `EditorWorkspace`、`EditorMenu`、`EditorRibbon`、`LyricList`、`LyricLine`、`LyricWord` 和选择/剪贴命令。 |
| 行词新建、插入、删除、复制、剪切、粘贴、跨行移动、桌面拖放排序/复制、触屏拖放排序 | 通过。内部词剪贴保留时间、Ruby、音译及对齐单元；行剪贴保留翻译、音译、背景及歌手。纯文本一行插词，多行插行。跨行词富剪贴按文档顺序合并到目标行，文本剪贴以换行分隔源行。 |
| Ctrl/Cmd 多选、Shift 范围、全选/反选/清空；焦点、选择、播放头区分 | 通过。词范围可跨行；行范围含背景的主行组。 |
| 行内正文/翻译/音译、词时间、混合属性、上下词定位、双击、Escape、IME | 通过。Alt+↑/↓ 跨行定位，离屏目标自动滚动。 |
| 大纲定位/排序、简单/高级布局、变高虚拟列表、双入口新画布 | 通过。长文档样本在本地入口验收；项目入口的编辑/保存/重开已覆盖。 |
| 撤销恢复排序与附属内容 | 通过。行组、词、Ruby、时间、翻译和批量属性均有行为验证。 |
