# E7 预览、格式与收尾验收

日期：2026-09-26。E7 的预览、文件格式和歌曲元数据已接入共用歌词工作区；以下记录实际可用范围与未完成的外部互通验证。

## 操作闭环

- 项目或本地文件均可切换编辑、打轴、预览。AMLL 0.5.2 预览直接读取当前未保存的语义草稿；项目页与 `MediaTransport` 共用播放位置和播放状态，点击预览歌词会选行并定位媒体。本地文件可拖动试听位置。Ruby、背景、对唱、翻译、音译由预览适配器提供，未定时间保留在草稿，不作为动态歌词传给 AMLL。翻译/音译、已播行和词渐变宽度可调整。
- 参考工具 Apple 样式 TTML 在项目页导入后，预览显示两段 Ruby、背景和翻译；点击主行定位 1.000 秒。随后修改 Ruby、保存、重新进入项目和下载最终 TTML，修改内容仍在。见 [1440px 预览](evidence/editor-e7/studio-preview-rich-1440.png)和[390px 预览](evidence/editor-e7/studio-preview-rich-390.png)。[390px 夜间编辑](evidence/editor-e7/studio-edit-dark-390.png)验证主题与底部播放器布局。
- 本地 `/editor` 使用同一文档与菜单，提供文件打开、新建、检查点保存/恢复、未保存提示和下载；项目页使用 revision/ETag 保存、冲突提示和本地草稿恢复。`LineTable` 等旧组件已不在工作区内；`LocalEditor` 仍是当前本地文件路由的容器，实际画布由共用 `EditorWorkspace` 承担。

## 文件格式方向

| 格式 | 导入 | 导出 | 表达边界 |
| --- | --- | --- | --- |
| TTML / Studio 草稿 TTML | 是 | 是 | 富歌词权威格式；最终导出要求有效时间；草稿保留未定时间和编辑辅助状态 |
| 纯文本 | 是 | 是 | 仅正文行，无时间、Ruby、背景或元数据 |
| LRC | 是 | 是 | 行时间；Ruby 和 Studio 元数据不保留 |
| ESLRC、QRC、YRC | 是 | 是 | 逐词时间经参考工具同版本格式库解析/生成；Ruby 不保留 |
| LYS | 是 | 是 | 可表达背景/对唱；Ruby 和任意元数据不保留 |
| ASS | 否 | 是 | 字幕导出；不作为可编辑歌词的导入源 |

非 TTML 导出在时间不完整时给出错误，避免静默产生错误文件。格式解析有 4 MB / 20,000 行边界；项目导入先写入当前草稿，用户检查后保存。标题、艺人、专辑、作者、自定义键、重复值和歌词语言可编辑，并经 TTML 草稿往返。歌词格式库直接依赖 `@applemusic-like-lyrics/lyric@1.0.2`；完整外部工具互通目前只有 TTML 富歌词样例验证，各低表达力格式仅完成库内时间往返及浏览器导入导出。

## 仍需外部验证

- 真正的长音频拖动帧率、更多商业媒体编码以及弱节拍歌曲的自动 BPM 准确率没有测量；目前的 30 分钟案例使用模拟 waveform。
- 低表达力格式尚未逐个在第三方播放器或参考工具中双向打开；Ruby、重复元数据和精细对齐只应使用 TTML 交换。预览只显示有完整时间的行/词，未定草稿需先打轴。
- 参考工具的全部菜单命令、主题细节和高级预览选项没有逐像素对齐；对齐矩阵保留这些差异，不将其算作通过。
