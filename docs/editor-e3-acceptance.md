# E3 分词与批处理验收

日期：2026-09-26。结论：**E3 的分词与数值批处理路径已实施并通过针对性验证**。E6 的可编辑时间轴、吸附和拖动仍按计划开发；此处不将它们计入 E3。

## 可操作结果

- 编辑 Ribbon 的“分词…”打开手动、自动、高级面板。手动模式对当前词的 grapheme 边界逐个切分或取消，并立即显示预览；自动/高级支持当前行、选中词或行、指定行范围、全文应用。CJK 可按字符切，西文可按词或按 E0 确认的八种语言音节切；标点可合并或独立，连续空白可独立或并入前后词。高级模式有时间权重、忽略列表、自定义规则和测试输入。
- 分词前保持原词文本和父时间区间；有双端时间时按累计权重算边界，末端精确等于原词结束时间；只有一端已定时保留该端。含 Ruby、音译或其他附属属性的词在预览中标明并跳过，不重置无关词。一次应用只写入一次撤销历史。相邻普通词可用词块上的“合”手动合并。
- “批处理…”提供词内文字替换、范围时间偏移、CJK 普通词近邻边界平滑、按词时间同步行首尾，以及当前主唱行结束时间链接到下一主唱行起点或取消链接。偏移同时移动行、词、Ruby 和对齐单元；负时间越界会使整次操作失败。平滑跳过 Ruby/对齐边界。链接保存原结束时间，目标行起点改变时自动更新；草稿 TTML 保存链接信息，最终 TTML 不带内部标记。

## 使用边界与后续阶段

- 手动边界面板一次处理当前词；多行和全文使用自动/高级规则，跨词的精确拆合使用画布词操作。批量替换只处理词块内部匹配，不跨词块拼接搜索。
- 平滑处理阈值内的 CJK 普通词边界；带 Ruby 的独立读音计时由 E4/E6 工作流处理。时间轴拖动、吸附和频谱仍属于 E6。
- 编辑文档和本地恢复记录升为 v4，旧 v3 开发检查点不自动迁移。原 TTML 文件和现有项目数据未删除；需要从原 TTML 重新导入旧开发草稿。
