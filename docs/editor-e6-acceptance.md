# E6 时间轴、频谱与 BPM 验收

日期：2026-09-26。E6 的可编辑时间轴、按需频谱和节拍定位已接入项目工作台。

## 操作与证据

- 波形下方显示行、当前行的词/Ruby、空隙和重叠轨道；拖动色块平移，拖两侧改变边界。行平移带着子时间和背景行，Ruby 调整同步父词包络。词轨空白拖动选择范围，已选词可成组移动；单次拖动只提交一个撤销事务，取消拖动不提交。空隙/重叠可点击闭合。时间标尺、缩放、窗口平移、滚轮平移、Ctrl/⌘ 滚轮缩放和播放跟随可用于定位。
- 节拍支持手动输入、Tap、从前 20 秒峰值自动估计、节拍线和可开关吸附。频谱只在不超过 20 秒的视窗请求 4 秒 PCM 片段，交由 Worker 计算并缓存；无需扫描整首音频。行、词、Ruby 轨道根据同一播放器时钟标出正在播放的块。
- [1440px 时间轴与频谱截图](evidence/editor-e6/studio-timeline-spectrum-1440.png)来自项目浏览器页面；合成音频和演示 PCM 分别驱动播放器与频谱。浏览器测试验证 120 BPM 检测、频谱片段加载和词拖动后一次撤销。

## 尚未覆盖

- 目前只有同一行内的词可通过轨道框选后成组平移；跨行范围可用 E3 批量偏移面板处理。节拍估计以波形峰值为输入，对弱鼓点歌曲需手动或 Tap 校正。
- 长音频按视窗请求波形和频谱，已有 2,000 行/20,000 词虚拟列表测试；没有真实长音频拖动的帧率测量。对齐参考工具的全部轨道细节和真实媒体试听仍需实测。
