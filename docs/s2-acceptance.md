## 已实现范围

`/editor` 是无需服务端会话的本地 TTML 工作区。S1 的服务端项目摘要仍为只读，未混用两种数据源。代码由 gpt-5.6-luna 子代理编写，主 Agent 负责审查、浏览器验证和界面验收。

- 富文档保留原始 XML、命名空间与节点树，内部行 ID 根据源节点路径生成，与 `xml:id` 分开。正文、空时间、agent 引用、Ruby code-point 范围和源时间上下文有独立投影。
- 普通纯文本行支持正文及绝对整数微秒时间修改；XML 写回使用 baseline DOM 定位，不从行表重建文件。父级相对时间及原 `dur` 在改动时正确换算，越界与逆序修改拒绝。
- Ruby、混合内容、逐字时间与未知扩展保留在源树；相关字段只读并展示原因。S2 不开放 Ruby/逐字时间编辑，也不声称已经实现这些结构的完整编辑投影。
- 草稿以 `urn:lazulite:studio:draft` 的 `null` 属性标明未定起止；未知帧/tick 时间不改写为未定。最终导出要求完整时间且通过当前 profile 检查；未支持的文件仍可下载原件或草稿。
- 行命令支持原子批量操作、最近 20 步撤销/重做和复核状态失效恢复。IndexedDB 检查点保存工作副本及有界历史，事务完成才确认写入，恢复时检查 schema 和各快照的文档基线。

这里的恢复仅限当前浏览器。服务器 revision、自动保存、冲突处理、媒体、agent 编辑与完整歌曲制作闭环分别属于后续阶段；检查点不等于服务器保存。
