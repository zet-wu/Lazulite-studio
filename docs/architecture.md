# Lazulite Studio 项目架构

2026-10-01 更新至获取与打包人工审阅后的 Phase 1 整改。执行依据见[本轮方案](../../lyric-workflow/docs/studio-search-release-review/Review-phase1/plan.md)，实际验证和开放项见[当前状态](../../lyric-workflow/docs/studio/current-state.md)。

## 1. 应用与目录

React 19 / TypeScript / Vite SPA，React Router 负责路由，TanStack Query 管理服务缓存，CSS Modules 管布局，TanStack Virtual 渲染变高列表。AMLL 0.5.2 按需预览；`hyphen` 与 `wanakana` 用于音节/假名处理。具体版本由 `frontend/package.json` 和锁文件固定。

| 位置 | 职责 |
| --- | --- |
| `frontend/src/app` | 路由、会话、Query provider、错误边界 |
| `frontend/src/features/editor` | 共用画布、行/词/Ruby、分词/批处理/音译、打轴、预览、菜单 |
| `frontend/src/features/Workspace.tsx` | 项目连接、保存、候选、词典/复核和媒体组合 |
| `frontend/src/features/MediaTransport.tsx`、`TimelineTracks.tsx` | 主媒体时钟、波形/PCM 声谱图、循环和时间轴 |
| `frontend/src/domain` | 语义文档、命令/历史、文本边界、分词、时间、预览投影 |
| `frontend/src/adapters` | HTTP、TTML、其他歌词格式、IndexedDB |
| `contracts` | OpenAPI 及生成类型来源，存在已知覆盖缺口 |
| `server` | FastAPI、SQLite、资产/修订文件、任务、读音和发布 |
| `tests/fixtures/ttml` | 前后端测试共用合成 TTML 输入；不依赖外部文档仓库 |

## 2. 路由与组合

`/editor` 由 LocalEditor 管本地文件与检查点，`/projects/:projectId/edit` 由 Workspace 管项目；两者使用同一个 EditorWorkspace、领域命令和 codec。项目路由有音频服务与保存冲突处理；本地路由没有同等媒体资产能力。

其他路由为 `/projects`、`/login`、`/settings`。编辑器提供歌词获取/编辑/打轴/预览/文件打包及末尾“项目辅助”占位；大纲、歌词列表、属性各自滚动；大纲点击在栏上委托，未变化行用memo复用，元数据、歌手与音译轨道通过编辑模式的“歌词设置”进入既有弹窗。两侧独立显隐，默认190px/250px，范围160–360px/200–420px；6px分隔条支持指针捕获、取消、键盘8/32px、双击默认。拖动直接预览grid几何，仅分隔条更新自身ARIA，松手才提交工作区偏好；单一localStorage偏好不进入文档/history，resize仅限制渲染宽度；普通/虚拟列表共用显式ID/serial定位：远端先挂载，再按真实卡片矩形平滑居中，超高卡片靠顶；有界校准，新请求及用户滚动取消，尊重reduced-motion，普通定位不抢焦点；输出错误项的显式定位请求选中稳定对象并转移键盘焦点。EditorMenu与EditorRibbon共用单一activeMenuId；受控details保留输入挂载，跨菜单互斥，命令/外点/Escape关闭（Escape回触发器），离开200ms关闭并保护菜单内键盘焦点；文件菜单已移除，导入在歌词获取、导出在文件打包。

界面以共享语义 tokens 定义明暗表面、主次操作及内容/标签层级；菜单使用无框整行项。SettingsDialog 统一标题、滚动内容和固定操作区，兼顾焦点圈定及返回。大纲/属性标题独立固定，大纲行号与歌词分列，属性用主行号及背景标识；中栏不再设标题工具栏，元数据、歌手和轨道管理统一放在编辑工具旁的“歌词设置”，打轴/预览不显示此入口。LyricList 在普通/虚拟内容的真实末尾渲染追加按钮，空文档同样可新增空白主行，选中并请求定位。

`InlineAdd` 为行末词与定时音译末尾提供同一个本地草稿输入，IME期间不响应Enter，非空Enter/blur只提交一次，Esc/空字符串取消不建占位，纯空白可作为独立词或音译单元新增；新对象保持未定时间并选中，既有虚拟列表保留焦点行挂载。词文本直接单击编辑，鼠标点击处理对象范围及修饰键，data-pointer-focus隔离被动鼠标焦点；键盘Tab定位仍选择对象，活动输入保留原生选字与文本菜单；F8用当前草稿原子编辑后按光标拆分。词右键默认拆分复用segmentText/distributeSegmentTime，默认空白为独立分片，长词可进入高级分词，附属属性阻止不安全分配。

`TranslationEditor` 用自动高度 textarea 管正文草稿，输入/宽度/恢复重新测量，单行起步、约六行封顶，保持 Enter/blur 提交与 IME/Esc；语言与垃圾桶紧凑排列。它管每条翻译的自由语言标签草稿、错误及删除；新条目提交非空正文后才写文档。`sublyrics.ts` 在命令及codec边界排除空翻译并校验语言格式，清空和图标删除可撤销。`SingerSelection`逐个歌手显示全选/未选/混合，批量只修改所选成员，其他引用及顺序保持。音译内容使用专用blue-soft背景及内描边，单元范围、键盘焦点及拖动占位保持独立。

`editor/object-drag.ts` 管理单对象指针会话。合法非输入区按下即抑制原生选字并捕获指针，歌词输入仍保留原生选区；副本只更新 DOM 坐标。二维矩形命中计算明确前驱槽位，只在槽位/复制模式变化时用纯命令生成临时文档投影，独立于实际文档/history。预览中的对象保留真实尺寸作占位，mounted 对象作 FLIP translate 动画，reduced-motion 禁用动画；虚拟行继续由 TanStack 挂载、测量和定位。松手提交同一槽位命令一次；取消、失捕、文档变化及卸载清理副本/捕获/占位。行组、词跨行及附属单元范围复用领域限制，行/词复制保留源对象。

## 3. 权威文档与事务

`LyricDocument`（`studio-lyric-v6`）为唯一可写歌词文档，含 lines、romanizationTracks、agents、metadata、language。行包含 words、背景父 ID、agentRefs、翻译与时间链接；词含 text、时间、Ruby 单元、对齐单元、空拍等。音译轨道按主行 ID 引用，保存语言、顺序、plain/timed 内容及定时单元。正文由词拼接，读音由 Ruby 拼接。

时间使用绝对整数毫秒/null；拆分坐标使用 code point 并检查 grapheme 边界。`lyric-commands.ts` 提供纯函数事务与 256 次历史。背景勾选时原子附属最近的前一主行，前行已占用即拒绝，不向更早或后方寻找；下拉仅建立关系后启用，显示动态Lx，value保留稳定ID。内容、链接及各单元自身时间由单一命令校验；背景建立/改绑及主行拆分归属允许父背景各自独立绝对时间，不截短背景或扩展父行。selection、focus、播放时钟不作为歌词权威内容；批量操作一次入历史，最终改动经 codec 保存。

`line-structure.ts` 为拆合行提供共享实际阻塞原因和当前 Lx 对象标识。拆行前行保留ID、起点并清除结束链接，后行继承原结束/链接/取消时间，外部入链仍指前行；翻译按源数组索引逐条前/后分配，与音译/背景一次提交。合并消除内部边界链接并继承末行外链；外部指向第二行的入链仅在开始时间相同才改绑，否则明确阻塞。LineSplitDialog上下结果直接显示正文、时间和附属归属。

`romanization-generation.ts` 按已有Ruby单元或无Ruby假名正文词生成ja-Latn，以行内带源归属的假名序列处理上下文。普通拼写复用wanakana，跨单元促音保留所属单元，拆开的拗音使用ky/ya类特殊分片；长音取行内前元音，未知读音隔断上下文，行末促音不借下一行。源单元数量/顺序及毫秒端点原样保留，不合时间包络、不猜新时间。相邻非空白片段的真实分隔空格附着前单元，源空白原样保存；空转换及手工清空使用空格占位，提示不进入文档。

RomanizationGenerationDialog自有静态正文/Ruby对照布局，无播放遮罩或对唱位置。普通模式只有行级text/hint结果，定时模式只有源归属/时间/text/hint单元；输入不改变结构。打开或输出切换生成一次，目标切换、输入及应用不再转换；切模式丢弃本窗手工文字，源变化阻塞。input/自动高度textarea持续挂载，悬停/焦点显示边框；非阻塞虚线提示与整体阻塞实线分开，Enter提交字段、Esc恢复并阻止整窗关闭，IME期间不处理提交/恢复。超过80行TanStack有界挂载，活动输入行保留，手工结果滚出重挂不丢失。应用当前结果一次batch，源正文/Ruby不变；新轨道追加，已有内容默认跳过，只替换明确指定的局部内容。未定时间允许生成草稿，纯输出中实际音译文字及单端点缺失继续要求补全；双端点未定的非空纯空白原位置输出文本节点。

`editing-actions.ts` 的deleteSelection与cutSelection共用原子删除，覆盖行、跨行词、Ruby、音译内容/单元；右键已选对象保留ID集合和范围锚点，删除消费有效选区，空选区禁用。直接删除不写剪贴板，成功后选择仍存在的行并聚焦画布。LocalEditor同步执行纯命令后才更新stateRef与React状态，异常可由画布dispatch准确展示且不破坏页面；项目容器同样先执行后提交。音译相邻合并继续原样拼接文字及已有时间包络。

词级与行级旧音译字段已移除，预览临时派生逐词音译与二侧歌手状态。音译轨道在主行下作为独立附属内容编辑；“从音译生成 Ruby”只在显式提交时把提案写入 Ruby，源轨道继续保留。候选判断采用10ms边缘容差：最大重叠>10ms才滤除其他≤10ms候选，全短/多候选仍人工。假名转换整词连接后与正文NFC相同，派生默认跳过；手动boolean覆盖保留用户取消，目标/输出/源变化按事件重算。对话框使用“跳过生成”，全跳过禁用应用，不新增空历史；>80行使用已有TanStack Virtual，仅挂载可见提案，全部状态以稳定row key保留，源选择按需展开，覆盖列表有界滚动。空及纯空白音译源在建提案时过滤，源数据不变；主行右键复用批量入口，比例按当前轨道、内容勾选及非空源行实时计算。生成不再要求时间扩展同意，也不保留扩展展示明细；必要的词/行包络计算仍与 Ruby 写入组成同一 batch，保留源时间、覆盖选择、过期及行尾链接检查。旧格式数据直接丢弃，不设迁移或双写。

## 4. 格式与保存

`adapters/ttml/lyric-codec.ts` 解析为语义文档并规范化导出，旧 XML 保留树模型已移除。支持常见词/Ruby/背景、行内和 iTunes sidecar 附属内容、当前草稿辅助属性，以及 AMLL 无命名空间子节点和绝对分钟时间修复；x-bg保留自身begin/end，解析用外层容器校验而不要求位于父p内；body dur计入背景结束时间，草稿studio:id保持背景ID。纯 TTML 导出中，无时间且无Ruby/对齐/空拍的纯空白词，以及双端点未定的非空纯空白音译单元，写为原始文本节点，xml:space保留连续/首尾/换行空白；草稿仍用span保存稳定ID和未定端点。预览0–0空白只属于播放投影。未知不支持内容会报错，不宣称任意 TTML 可无损编辑。

`lyric-formats.ts` 支持文本、LRC/扩展 LRC/ESLRC/QRC/YRC/LYS 双向、KRC 导入与 ASS 导出。`source-codec.ts` 解析原始 QRC/YRC/KRC 和附属内容；本地二进制 KRC 在浏览器解压。`lrc.ts` 统一普通/尖括号扩展 LRC 下载和内嵌文本：只取主行正文，未知结束不猜测，重叠主行保留且仅在已知区间并集外清屏。低表达力格式不能携带全部 Ruby/元数据或多条音译轨道。预览动态正文使用有效完整时间，独立纯空白词按原顺序以0–0 AMLL word投影；其他未定时正文不进入动态预览，整行无定时词沿用正文回退，不修改文档。isDuet 从歌手引用派生；引用包含主唱时显示主唱侧，否则显示另一侧，无法可视化多歌手合唱。StudioLyricPlayer使用AMLL的单一DOM播放器，关闭自动时间改写，仅把父/背景显示组活跃区设为两行时间并集，保持各行及词/Ruby输入时间。

项目由 `useProjectDocument` 持有本地副本、dirty、revision/ETag、保存序号和冲突。IndexedDB 保存当前格式检查点；FastAPI 接受 TTML envelope，不接收浏览器对象图。修订以不可变文件与 DB 指针提交。候选只能由用户应用。

## 5. 媒体与服务

PlaybackSpeed提供0.1–2×即时滑条、0.05步长、累积并规范化滚轮/触控板增量、键盘和恢复1×；偏好保存在本地，不入歌词历史。速度仅在控件区域滚轮调整。MediaTransport在倍率、资产/项目变化及metadata加载时显式设置preservesPitch=true，不提供关闭入口，不引入第二播放器。HTMLMediaElement 为项目主时钟，媒体代理 offset 在边界转换；服务提供音频 Range、窗口 peaks 和 PCM。PCM代理固定48kHz双声道s16le，Studio时间从解码样本0开始，播放offset为0；PCM请求最多4.02秒，包含FFT上下文。声谱图 Worker 按需计算，BPM 提供手动/Tap/自动估计。时间轴用毫秒 viewport 显示波形、标尺与歌词轨道，普通滚轮按指针锚点缩放、空白处拖动平移；A/B 仅有一个数值区间状态，当前行/单元命令写入当时精确边界，不和歌词历史绑定。

波形、标尺、A/B、声谱图与歌词轨道共享36px标签和5px间距后的实际绘图区；边框采用内阴影，不占时间映射宽度。顶部显示视窗，定位A/B位于底部循环组；行、词、Ruby分别用确定性O(n log n)区间分轨，先筛选与视窗相交的真实区间，释放所有结束轨并优先复用最低空闲编号；空闲平移/缩放重排，色块/边界拖动冻结本次轨号和高度，提交/取消后更新。删除行抽样和最小色块宽度；视窗裁剪不伪造端点；无额外边界工具行或专用放大，窄块以既有滚轮/加号缩放后拖动普通端点，最小视窗10ms。绘图区整体限制高度并纵向滚动，控制组保留。背景和所选定时音译另有只读轨道。播放/时间/三角按钮持续挂载；收起取消min-height，仅卸载昂贵图层。播放位置约80ms更新轨道，暂停/seeked同步最终位置；普通色块用独立伪元素高亮，窄块仅真实颜色层高亮，选择与焦点可组合。

声谱图使用4秒核心片、512点Hann FFT和固定384×96显示网格（频率范围/色标不变）；视窗超过20秒提示放大。最多128个强度tile的简单LRU约4.5MiB，PCM转移后释放，不保留持久RGBA/位图；同时最多2个在途请求，取消离开视窗的网络工作；已进入Worker的过期计算直接终止并重建Worker，防止快速平移堆积任务，token拒绝过期结果。项目/资产/算法身份决定实例生命周期，隐藏/收起卸载后停止提交并释放Worker；分片两侧按48kHz样本位置请求半FFT上下文，Worker仅生成核心列，末片按真实时长绘制；Canvas相邻片共用取整设备像素边界。波形/频谱共用ResizeObserver及DPR变化监听，设备像素尺寸随显示变化重建。加载/失败片段与低能量颜色分开，失败有显式重试。

服务为登录用户共享项目库的单工作台，显式配置会话/网关模式。任务状态持久化，SSE 提供变化，结果从资源接口读取。reading、词典与实验 forced 的可用性取决于配置；HTTP 通过不代表模型质量。

`LyricAcquisition` 组合文件、文本和四网络来源，静态预览分页并展示 Ruby/翻译/音译。元数据每键选择原值或待导入完整列表，选择空侧删除；文档变化时重新对照。确认用一次 replace-document 事务，正文/歌手/音译整体替换，撤销全部恢复。网易 ID 和 QQ songmid 是字符串数组追加去重，酷狗/AMLL 不提供 ID 关联。

EditorWorkspace 持有 `AcquisitionStore` 与独立 `useSearchConditions`，切来源/编辑模式保留最近一轮。标题有限转换去重后同时搜索四源，增量合并稳定候选 ID；`domain/lyric-search.ts` 使用 fuzzball 与 OpenCC 按标题/专辑/艺术家身份排序，鼠标或键盘在列表内时延迟重排。改输入保留旧轮，显式搜索创建新轮，取消保留已到结果。搜索、主动取词与后台检查每源共享 3 个请求额度；全文获取与解析全局最多 2 个，用户选择和可见来源优先。完整文档缓存最多 8 个，包含每源选择的 4 个保留槽；后台仅更新自身记录，不选择或导入。

`lyric_sources.py` 在服务端处理固定四源检索、原始载荷取回和 QRC/KRC 解密解压；登录/CSRF、并发、超时及载荷上限在边界执行。前端唯一 codec 生成文档与实际属性，可靠正文保留真实逐词时间；附属按 750ms 向前单调一对一挂接，同起点歧义跳过。实际属性蓝色、处理中和部分失败黄色、无有效正文红色；异常提示在预览内短行呈现并可关闭，可靠正文的附属失败可普通确认导入。

`PackagingPanel` 使用格式下拉与单一下载按钮，TTML 固定纯输出；内部 CAS 保存与恢复检查点保留编辑属性。`output-validation.ts` 按目标实际内容收集全部结构化问题，`OutputIssues` 每项直接可点击/Enter 激活，显示主行/背景和对象序号，不展示 UUID 或歌词。稳定 ID 定位覆盖普通与虚拟行、词、Ruby 和音译。

`MusicPackaging` 捕获当前 document，先校验并保存，再用返回的确切 revision 创建任务。保存中继续编辑保持 dirty，旧任务不会代表新草稿；冲突/未确认恢复阻止创建。源文件按实际探测容器展示格式和写入策略；历史产物绑定任务资产、输出容器、回读报告与实际 STPP ID，不使用当前文件重写旧记录。仅成功回读报告开放下载。

`project_deletion.py` 在数据库写锁下拒绝未终态任务，暂存项目修订和产物文件后删除关联记录；失败恢复暂存。共享源音频与代理保留以避免上传/读取竞争。前端删除广播和保存 404 停止已开工作区并清理恢复数据。`search_conditions.py` 单独保存标题/艺术家/专辑三个最终字符串，创建时读音频标签多值或上传文件名；旧项目默认全空，不读 TTML 或自动回填。

`packaging.py` 通过 Mutagen 写 MP3 的 USLT::eng、FLAC 的 LYRICS、MP4 的 ©lyr；`publishing.py` 为非分片 MP4/M4A 添加或替换单 sample STPP。已有 STPP 必须显式选稳定 track ID，其他轨道和标签保留。对音频 packet hash、非目标标签/FLAC 元数据块、MP4 原 mdat 与去除地址差异的轨道结构、两部分歌词分别回读验证。源资产不覆盖、不转码；产物按实际探测格式选择扩展名，并按任务独立保存。发布副本原位置转换双端点未定的非空纯空白音译，原修订不变；失败或取消清理临时产物，完成写锁再次检查取消状态。外部播放器兼容性仍需单独验证。

## 6. 文档与依赖边界

领域不依赖 HTTP/DOM；适配器处理格式和服务，功能组件组合交互。模型变化时直接更新当前实现，不建立旧 schema 双写/回退。必要输入校验、撤销和保存一致性仍保留。

本仓库保留本文、模块结构说明与 AGENTS.md。方案、运行手册、过程及验收在 [lyric-workflow/docs/studio](../../lyric-workflow/docs/studio/README.md)，两者冲突时更新实际架构说明，不能把未来方案混成已实现状态。


## 当前交互与输出边界

工作区从活动画布选择派生唯一 `SyncCursor`，面板不保留另一份游标。正文映射到首个注音（如有），不参与序列的对象显示禁用。连续/本行模式共用领域落点；本行模式在领域层阻断跨行后继写入，完成后保留目标与播放状态。打轴自动行包络包含原边界，只向外扩；文档事务继续负责链接合法性与一次撤销。

注音字段持续可编辑，三个新增入口共用实际插入位置的 UI 草稿。草稿处理组合输入、Enter/失焦去重与取消，不向文档预写空对象；歌手新增在管理窗口内完成。手工整体注音命令已删除，任务读音候选由相邻词合并和添加注音组成一次批事务。

`features/shortcuts.ts` 是 12 项可配置快捷键的存储、展示和匹配来源；本机偏好不进入文档历史，合法旧打轴键位在读取边界迁移。全局播放与打轴检查重叠，播放器定位保持自身焦点范围，文本/控件/菜单/对话框优先。右上角设置打开统一快捷键窗口。默认编辑与打轴工具栏共用紧凑行高，回听/校准显式展开。

`StudioLyricPlayer.syncMedia` 读取唯一媒体时间和实际倍率，通过行元素的具名 Web Animations 适配渐变、浮动与强调相位，保留反向退场；不读私有分词数组，不改变布局弹簧或歌词时间。暂停播放线在视窗和展开状态变化时仅重新投影，不调用播放位置回调。

项目列表直接显示危险色垃圾桶，保留删除确认和原有服务保护。打包根据真实容器判别视频与附带封面，保留相容源后缀；输出文件继续用独立内部名称，任务结果保存当时项目名生成的可下载名称，下载响应和历史展示使用该名称。历史无名称结果仍可按原路径文件名下载。
