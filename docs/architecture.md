# Lazulite Studio 项目架构

2026-10-07 更新至时间轴 Phase 3。执行依据见[本轮方案](../../lyric-workflow/docs/studio-timeline-review/Review-phase3/plan.md)，实际验证和开放项见[当前状态](../../lyric-workflow/docs/studio/current-state.md)。

## 1. 应用与目录

React 19 / TypeScript / Vite SPA，React Router 负责路由，TanStack Query 管理服务缓存，CSS Modules 管布局，TanStack Virtual 渲染变高列表。AMLL 0.5.2 按需预览；`hyphen` 与 `wanakana` 用于音节/假名处理。具体版本由 `frontend/package.json` 和锁文件固定。

| 位置 | 职责 |
| --- | --- |
| `frontend/src/app` | 路由、会话、Query provider、错误边界 |
| `frontend/src/features/editor` | 共用画布、行/词/Ruby、分词/批处理/音译、打轴、预览、菜单 |
| `frontend/src/features/Workspace.tsx` | 项目连接、保存、候选、词典/复核和媒体组合 |
| `frontend/src/features/MediaTransport.tsx`、`TimelineTracks.tsx` | 主媒体时钟、波形/PCM 声谱图、循环和时间轴 |
| `frontend/src/domain` | 语义文档、命令/历史、文本边界、分词、时间、预览投影 |
| `frontend/src/adapters` | HTTP、TTML、其他歌词格式、IndexedDB |
| `contracts` | OpenAPI 及生成类型来源，存在已知覆盖缺口 |
| `server` | FastAPI、SQLite、资产/修订文件、任务、读音和发布 |
| `tests/fixtures/ttml` | 前后端测试共用合成 TTML 输入；不依赖外部文档仓库 |

## 2. 路由与组合

`/editor` 由 LocalEditor 管本地文件与检查点，`/projects/:projectId/edit` 由 Workspace 管项目；两者使用同一个 EditorWorkspace、领域命令和 codec。项目路由有音频服务与保存冲突处理；本地路由没有同等媒体资产能力。

其他路由为 `/projects`、`/login`、`/settings`。编辑器提供歌词获取/音频处理/编辑/打轴/预览/文件打包及末尾“项目辅助”占位；大纲、歌词列表、属性各自滚动；大纲点击在栏上委托，未变化行用memo复用，元数据、歌手与音译轨道通过编辑模式的“歌词设置”进入既有弹窗。音频页复用同一大纲分隔条与宽度偏好，按两栏约束计算且不扣除属性栏；隐藏侧栏时焦点可回主栏。两侧独立显隐，默认190px/250px，范围160–360px/200–420px；6px分隔条支持指针捕获、取消、键盘8/32px、双击默认。拖动直接预览grid几何，仅分隔条更新自身ARIA，松手才提交工作区偏好；单一localStorage偏好不进入文档/history，resize仅限制渲染宽度；普通/虚拟列表共用显式ID/serial定位：远端先挂载，再按真实卡片矩形平滑居中，超高卡片靠顶；有界校准，新请求及用户滚动取消，尊重reduced-motion，普通定位不抢焦点；输出错误项的显式定位请求选中稳定对象并转移键盘焦点。EditorMenu与EditorRibbon共用单一activeMenuId；受控details保留输入挂载，跨菜单互斥，命令/外点/Escape关闭（Escape回触发器），离开200ms关闭并保护菜单内键盘焦点；文件菜单已移除，导入在歌词获取、导出在文件打包。

界面以共享语义 tokens 定义明暗表面、主次操作及内容/标签层级；菜单使用无框整行项。SettingsDialog 统一标题、滚动内容和固定操作区，兼顾焦点圈定及返回。大纲行无框，aria-pressed 表达当前选中，每条已选行显示底色与侧边标记，焦点单独表达。大纲/属性标题独立固定，大纲行号与歌词分列，属性用主行号及背景标识；中栏不再设标题工具栏，元数据、歌手和轨道管理统一放在编辑工具旁的“歌词设置”，打轴/预览不显示此入口。LyricList 在普通/虚拟内容的真实末尾渲染追加按钮，空文档同样可新增空白主行，选中并请求定位。

`InlineAdd` 为行末词与定时音译末尾提供同一个本地草稿输入，IME期间不响应Enter，非空Enter/blur只提交一次，Esc/空字符串取消不建占位，纯空白可作为独立词或音译单元新增；新对象保持未定时间并选中，既有虚拟列表保留焦点行挂载。词文本直接单击编辑，鼠标点击处理对象范围及修饰键，data-pointer-focus隔离被动鼠标焦点；键盘Tab定位仍选择对象，活动输入保留原生选字与文本菜单；F8用当前草稿原子编辑后按光标拆分。词右键默认拆分复用segmentText/distributeSegmentTime，默认空白为独立分片，长词可进入高级分词，附属属性阻止不安全分配。

`TranslationEditor` 用自动高度 textarea 管普通正文草稿，Enter/blur 提交、IME/Esc 与定时单元编辑共用现有规则。内容仅持有行引用、结构、文字及时间；轨道语言、用途和顺序由 `TranslationTrackDialog` 统一管理。显式归轨按内容 ID 保留结构与目标原有内容，来源变化整体拒绝；语言清除、删除、排序和归轨在提案中一次应用。`SingerSelection`逐个歌手显示全选/未选/混合，批量只修改所选成员，其他引用及顺序保持。音译内容使用专用blue-soft背景及内描边，单元范围、键盘焦点及拖动占位保持独立。

`editor/object-drag.ts` 管理指针会话和完整选区。合法非输入区按下即抑制原生选字并捕获指针，歌词输入保留原生选区；达到阈值后显示副本及不占布局的插入线。二维矩形命中带小幅滞回；逐帧读取当前几何，候选变化时由同一领域命令校验，不重排原文档。仅允许的歌词列表／大纲在边缘停留后渐进滚动，触发区域沿其水平范围延伸到容器上下方；外部滚动区域不作为投放目标。大纲点击定位只在未进入拖动的松手时触发。松手一次提交；无效落点以副本红色虚线外框提示，不渲染文字、不改变副本尺寸，并拒绝提交，取消、失捕、文档变化及卸载清理副本／捕获／插入线。行组、词跨行及附属单元范围复用领域限制，行／词复制保留源对象并重映射身份与配置。

## 3. 权威文档与事务

`ProjectDocument`（`studio-project-v2`）是唯一项目编辑状态，包含源资产 ID、结构化 lyrics 与 acoustics（采用结果 ID、片段副本）。其中 `LyricDocument`（`studio-lyric-v9`）为歌词部分，含 lines、romanizationTracks、translationTracks、agents、metadata、language。行包含 words、背景父 ID、agentRefs 与实际时间；词含 text、时间、Ruby 单元、对齐单元等。项目 editing 独立保存词／Ruby 空拍、忽略行与行尾链接；关系和歌词实际端点在同一项目事务内维护。音译轨道按主行或背景行的稳定 ID 引用，保存语言、顺序、plain/timed 内容及定时单元。正文由词拼接，读音由 Ruby 拼接。

时间使用绝对整数毫秒/null；拆分坐标使用 code point 并检查 grapheme 边界。`lyric-commands.ts` 提供纯函数歌词事务；运行时只有 `project-document.ts` 提交 256 次项目历史，歌词与声学操作按实际顺序统一撤销。背景勾选时原子附属最近的前一主行，前行已占用即拒绝，不向更早或后方寻找；下拉仅建立关系后启用，显示动态Lx，value保留稳定ID。内容、链接及各单元自身时间由单一命令校验；背景建立/改绑及主行拆分归属允许父背景各自独立绝对时间，不截短背景或扩展父行。selection、focus、播放时钟不作为歌词权威内容；批量操作一次入历史，最终改动经 codec 保存。

`line-structure.ts` 为拆合行提供共享实际阻塞原因和当前 Lx 对象标识。拆行前行保留ID、起点并清除结束链接，后行继承原结束/链接，外部入链仍指前行；翻译按稳定内容 ID 逐条前/后分配，与音译/背景一次提交。合并消除内部边界链接并继承末行外链；外部指向第二行的入链仅在开始时间相同才改绑，否则明确阻塞。LineSplitDialog上下结果直接显示正文、时间和附属归属。

`romanization-generation.ts` 按已有Ruby单元或无Ruby假名正文词生成ja-Latn，以行内带源归属的假名序列处理上下文。普通拼写复用wanakana，跨单元促音保留所属单元，拆开的拗音使用ky/ya类特殊分片；长音取行内前元音，未知读音隔断上下文，行末促音不借下一行。源单元数量/顺序及毫秒端点原样保留，不合时间包络、不猜新时间。相邻非空白片段的真实分隔空格附着前单元，源空白原样保存；空转换及手工清空使用空格占位，提示不进入文档。

RomanizationGenerationDialog自有静态正文/Ruby对照布局，无播放遮罩或对唱位置。普通模式只有行级text/hint结果，定时模式只有源归属/时间/text/hint单元；输入不改变结构。打开或输出切换生成一次，目标切换、输入及应用不再转换；切模式丢弃本窗手工文字，源变化阻塞。input/自动高度textarea持续挂载，悬停/焦点显示边框；非阻塞虚线提示与整体阻塞实线分开，Enter提交字段、Esc恢复并阻止整窗关闭，IME期间不处理提交/恢复。超过80行TanStack有界挂载，活动输入行保留，手工结果滚出重挂不丢失。应用当前结果一次batch，源正文/Ruby不变；新轨道追加，已有内容默认跳过，只替换明确指定的局部内容。未定时间允许生成草稿，纯输出中实际音译文字及单端点缺失继续要求补全；双端点未定的非空纯空白原位置输出文本节点。

`editing-actions.ts` 的deleteSelection与cutSelection共用原子删除，覆盖行、跨行词、Ruby、音译内容/单元；右键已选对象保留ID集合和范围锚点，删除消费有效选区，空选区禁用。直接删除不写剪贴板，成功后选择仍存在的行并聚焦画布。浏览器剪贴事件仅在编辑/打轴的歌词对象区域且有选区时接管；文本输入、弹窗与页面文字选区保留原生行为，菜单显式剪贴仍针对对象。快捷键撤销/重做若移除了焦点对象，下一帧将焦点回落画布，不添加全局监听。LocalEditor同步执行纯命令后才更新stateRef与React状态，异常可由画布dispatch准确展示且不破坏页面；项目容器同样先执行后提交。音译相邻合并继续原样拼接文字及已有时间包络。

词级与行级旧音译字段已移除，预览临时派生逐词音译与二侧歌手状态。音译轨道在主行和背景行下作为独立附属内容编辑；“从音译生成 Ruby”只在显式提交时把提案写入 Ruby，源轨道继续保留。候选判断采用50ms边缘容差：最大重叠>50ms才滤除其他≤50ms候选，全短/多候选仍人工。假名转换整词连接后与正文NFC相同，派生默认跳过；手动boolean覆盖保留用户取消，目标/输出/源变化按事件重算。对话框使用“跳过生成”，全跳过禁用应用，不新增空历史；>80行使用已有TanStack Virtual，仅挂载可见提案，全部状态以稳定row key保留，源选择按需展开，覆盖列表有界滚动。空、纯空白及明确的纯非读音标点音译源在建提案时过滤，源数据不变；歌词行右键复用批量入口，比例按当前轨道、内容勾选及非空源行实时计算。生成不再要求时间扩展同意，也不保留扩展展示明细；必要的词/行包络计算仍与 Ruby 写入组成同一 batch，保留源时间、覆盖选择、过期及行尾链接检查。旧格式数据直接丢弃，不设迁移或双写。

## 4. 格式与保存

`adapters/ttml/lyric-codec.ts` 解析为语义文档并规范化导出，旧 XML 保留树模型已移除。支持常见词/Ruby/背景、行内和 iTunes sidecar 附属内容、当前草稿辅助属性，以及 AMLL 无命名空间子节点和绝对分钟时间修复；x-bg保留自身begin/end，解析用外层容器校验而不要求位于父p内；body dur计入背景结束时间，草稿studio:id保持背景ID。纯 TTML 导出中，无时间且无Ruby/对齐/空拍的纯空白词，以及双端点未定的非空纯空白音译单元，写为原始文本节点，xml:space保留连续/首尾/换行空白；草稿仍用span保存稳定ID和未定端点。预览0–0空白只属于播放投影。未知不支持内容会报错，不宣称任意 TTML 可无损编辑。

`lyric-formats.ts` 支持文本、LRC/扩展 LRC/ESLRC/QRC/YRC/LYS 双向、KRC 导入与 ASS 导出。`source-codec.ts` 解析原始 QRC/YRC/KRC 和附属内容；本地二进制 KRC 在浏览器解压。`lrc.ts` 统一普通/尖括号扩展 LRC 下载和内嵌文本：只取主行正文，未知结束不猜测，重叠主行保留且仅在已知区间并集外清屏。低表达力格式不能携带全部 Ruby/元数据或多条音译轨道。预览动态正文使用有效完整时间，独立纯空白词按原顺序以0–0 AMLL word投影；其他未定时正文不进入动态预览，整行无定时词沿用正文回退，不修改文档。isDuet 从歌手引用派生；引用包含主唱时显示主唱侧，否则显示另一侧，无法可视化多歌手合唱。StudioLyricPlayer使用AMLL的单一DOM播放器，关闭自动时间改写，仅把父/背景显示组活跃区设为两行时间并集，保持各行及词/Ruby输入时间。

项目由 `useProjectDocument` 持有本地副本、dirty、revision/ETag、保存序号和冲突。IndexedDB 保存完整当前项目与基础修订，重开不恢复撤销栈。FastAPI 接受 `studio-document-v4` envelope，document 为 JSON 项目快照，lyrics 保存 draftTtml；修订以不可变 JSON 文件和 project_path 指针提交，不双写旧 TTML 修订。歌词导入仅替换 lyrics，声学数据保留；发布捕获完整快照并从确切修订提取歌词。复核只比较歌词语义。候选由用户明确采用；人声处理由用户启动后在成功时按捕获的声学基线自动接入，真实冲突才提供明确替换入口。

## 5. 媒体与服务

PlaybackSpeed提供0.1–2×即时滑条、0.05步长、累积并规范化滚轮/触控板增量、键盘和恢复1×；偏好保存在本地，不入歌词历史。速度仅在控件区域滚轮调整。MediaTransport在倍率、资产/项目变化及metadata加载时显式设置preservesPitch=true，不提供关闭入口，不引入第二播放器。HTMLMediaElement 为项目主时钟，媒体代理 offset 在边界转换；服务提供音频 Range、窗口 peaks 和 PCM。PCM代理固定48kHz双声道s16le，Studio时间从解码样本0开始，播放offset为0；PCM请求最多4.02秒，包含FFT上下文。声谱图 Worker 按需计算，BPM 提供手动/Tap/自动估计。时间轴用毫秒 viewport 显示波形、标尺与歌词轨道，普通滚轮按指针锚点缩放、空白处拖动平移；A/B 仅有一个数值区间状态，当前行／循环选区命令写入当时精确边界，不和歌词历史绑定。

波形、标尺、A/B、声谱图与歌词轨道共享52px标签和5px间距后的实际绘图区；边框采用内阴影，不占时间映射宽度。顶部显示视窗，定位A/B位于底部循环组；行、词、Ruby分别用确定性O(n log n)区间分轨，先筛选与视窗相交的真实区间，释放所有结束轨并优先复用最低空闲编号；空闲平移/缩放重排，色块/边界拖动冻结本次轨号和高度，提交/取消后更新。删除行抽样和最小色块宽度；视窗裁剪不伪造端点；无额外边界工具行或专用放大，窄块以既有滚轮/加号缩放后拖动普通端点，最小视窗10ms。绘图区整体限制高度并纵向滚动，控制组保留。主／背景行同等交互；展开行按 Lx／背景分组，词、Ruby、定时音译分别分轨。展开集合独立于有效选择，长列表纵向虚拟化并按时间视窗裁剪；音译有独立图层，普通与未定时内容不伪造色块。播放/时间/三角按钮持续挂载；收起取消min-height，仅卸载昂贵图层。播放位置约80ms更新轨道，暂停/seeked同步最终位置；普通色块用独立伪元素高亮，窄块仅真实颜色层高亮，选择与焦点可组合。

声谱图使用4秒核心片、512点Hann FFT和固定384×96显示网格（频率范围与强度范围不变）；视窗超过20秒提示放大。最多128个强度tile的简单LRU约4.5MiB，PCM转移后释放，不保留持久RGBA/位图；同时最多2个在途请求，取消离开视窗的网络工作；已进入Worker的过期计算直接终止并重建Worker，防止快速平移堆积任务，token拒绝过期结果。项目/资产/算法身份决定实例生命周期，隐藏/收起卸载后停止提交并释放Worker；分片两侧按48kHz样本位置请求半FFT上下文，Worker仅生成核心列，末片按真实时长绘制；Canvas相邻片共用取整设备像素边界。波形/频谱共用ResizeObserver及DPR变化监听，设备像素尺寸随显示变化重建。加载/失败片段与低能量颜色分开，失败有显式重试。

服务为登录用户共享项目库的单工作台，显式配置会话/网关模式。任务状态持久化，SSE 提供变化，结果从资源接口读取。reading、词典与实验 forced 的可用性取决于配置；HTTP 通过不代表模型质量。

`LyricAcquisition` 组合文件、文本和四网络来源，静态预览分页并展示 Ruby/翻译/音译。元数据每键选择原值或待导入完整列表，选择空侧删除；文档变化时重新对照。确认用一次 replace-document 事务，正文/歌手/音译整体替换，撤销全部恢复。网易 ID 和 QQ songmid 是字符串数组追加去重，酷狗/AMLL 不提供 ID 关联。

EditorWorkspace 持有 `AcquisitionStore` 与独立 `useSearchConditions`，切来源/编辑模式保留最近一轮。候选项按内容排高、不参与纵向收缩，列表滚动；关联/重新取词与来源限制提示共用固定操作行。标题有限转换去重后同时搜索四源，增量合并稳定候选 ID；`domain/lyric-search.ts` 使用 fuzzball 与 OpenCC 按标题/专辑/艺术家身份排序，鼠标或键盘在列表内时延迟重排。改输入保留旧轮，显式搜索创建新轮，取消保留已到结果。搜索、主动取词与后台检查每源共享 3 个请求额度；全文获取与解析全局最多 2 个，用户选择和可见来源优先。完整文档缓存最多 8 个，包含每源选择的 4 个保留槽；后台仅更新自身记录，不选择或导入。

`lyric_sources.py` 在服务端处理固定四源检索、原始载荷取回和 QRC/KRC 解密解压；登录/CSRF、并发、超时及载荷上限在边界执行。前端唯一 codec 生成文档与实际属性，可靠正文保留真实逐词时间；附属按 750ms 向前单调一对一挂接，同起点歧义跳过。实际属性蓝色、处理中和部分失败黄色、无有效正文红色；异常提示在预览内短行呈现并可关闭，可靠正文的附属失败可普通确认导入。

`PackagingPanel` 使用格式下拉与单一下载按钮，TTML 固定纯输出；内部 CAS 保存与恢复检查点保留编辑属性。`output-validation.ts` 按目标实际内容收集全部结构化问题，`OutputIssues` 每项直接可点击/Enter 激活，显示主行/背景和对象序号，不展示 UUID 或歌词。稳定 ID 定位覆盖普通与虚拟行、词、Ruby 和音译。

`MusicPackaging` 并列提供“打包文件”与“下载产物”，无可用记录或读取失败时下载按钮禁用；新任务运行、失败或取消期间仍可下载有效旧产物，任务卡片保留修订及过期提示。下载链接复用次要按钮样式及浏览器直接下载。它捕获当前 document，先校验并保存，再用返回的确切 revision 创建任务。保存中继续编辑保持 dirty，旧任务不会代表新草稿；冲突/未确认恢复阻止创建。源文件按实际探测容器展示格式和写入策略；历史产物绑定任务资产、输出容器、回读报告与实际 STPP ID，不使用当前文件重写旧记录。仅成功回读报告开放下载。

`project_deletion.py` 在数据库写锁下拒绝未终态任务，暂存项目修订和产物文件后删除关联记录；失败恢复暂存。共享源音频与代理保留以避免上传/读取竞争。前端删除广播和保存 404 停止已开工作区并清理恢复数据。`search_conditions.py` 单独保存标题/艺术家/专辑三个最终字符串，创建时读音频标签多值或上传文件名；旧项目默认全空，不读 TTML 或自动回填。

`packaging.py` 通过 Mutagen 写 MP3 的 USLT::eng、FLAC 的 LYRICS、MP4 的 ©lyr；`publishing.py` 为非分片 MP4/M4A 添加或替换单 sample STPP。已有 STPP 必须显式选稳定 track ID，其他轨道和标签保留。对音频 packet hash、非目标标签/FLAC 元数据块、MP4 原 mdat 与去除地址差异的轨道结构、两部分歌词分别回读验证。源资产不覆盖、不转码；产物按实际探测格式选择扩展名，并按任务独立保存。发布副本原位置转换双端点未定的非空纯空白音译，原修订不变；失败或取消清理临时产物，完成写锁再次检查取消状态。外部播放器兼容性仍需单独验证。

## 6. 文档与依赖边界

领域不依赖 HTTP/DOM；适配器处理格式和服务，功能组件组合交互。模型变化时直接更新当前实现，不建立旧 schema 双写/回退。必要输入校验、撤销和保存一致性仍保留。

本仓库保留本文、模块结构说明与 AGENTS.md。方案、运行手册、过程及验收在 [lyric-workflow/docs/studio](../../lyric-workflow/docs/studio/README.md)，两者冲突时更新实际架构说明，不能把未来方案混成已实现状态。


## 当前交互与输出边界

工作区从活动画布选择派生唯一 `SyncCursor`，面板不保留另一份游标。正文映射到首个注音（如有），不参与序列的对象显示禁用。连续/本行模式共用领域落点；本行模式在领域层阻断跨行后继写入，完成后保留目标与播放状态。打轴自动行包络包含原边界，只向外扩；文档事务继续负责链接合法性与一次撤销。

注音字段持续可编辑，三个新增入口共用实际插入位置的 UI 草稿。草稿处理组合输入、Enter/失焦去重与取消，不向文档预写空对象；歌手新增在管理窗口内完成。手工整体注音命令已删除，任务读音候选由相邻词合并和添加注音组成一次批事务。

`features/shortcuts.ts` 是 12 项可配置快捷键的存储、展示和匹配来源；本机偏好不进入文档历史，合法旧打轴键位在读取边界迁移。全局播放与打轴检查重叠，播放器定位保持自身焦点范围，文本/控件/菜单/对话框优先。右上角设置打开统一快捷键窗口。默认编辑与打轴工具栏共用紧凑行高，回听/校准显式展开。

`StudioLyricPlayer.syncMedia` 读取唯一媒体时间和实际倍率，通过行元素的具名 Web Animations 适配渐变、浮动与强调相位，保留反向退场；不读私有分词数组，不改变布局弹簧或歌词时间。暂停播放线在视窗和展开状态变化时仅重新投影，不调用播放位置回调。

项目列表直接显示危险色垃圾桶，保留删除确认和原有服务保护。打包根据真实容器判别视频与附带封面，保留相容源后缀；输出文件继续用独立内部名称，任务结果保存当时项目名生成的可下载名称，下载响应和历史展示使用该名称。历史无名称结果仍可按原路径文件名下载。


## 毫秒时间与输出生命周期

项目文档为 `studio-project-v2`，歌词部分仍为 `studio-lyric-v9`：`TimeMs`、`beginMs/endMs`、打轴和 A/B 均为整数毫秒或 `null`。行尾链接存 editing.endLinks 来源 ID → 目标 ID，普通解除、分配解除和删除目标均冻结当前有效结束时间，不保留旧端点。文档接口为 `studio-document-v4`，媒体与任务契约使用 `_ms`。恢复检查点使用独立 project-v2 数据库，旧检查点不再读取；没有旧结构转换或双写。媒体元素仍用秒，PCM 仍按样本帧，编码 timescale 不改。

TTML 解析先处理相对祖先得到实际端点，再按半毫秒向上舍入；时钟写法（包括带小时）为绝对时间。保存、下载与 STPP 使用三位毫秒时钟，零时长舍入不自动延长。`server/time_units.py` 在修订写入边界规范化，并保留正文及 Apple 头部元素的默认命名空间，避免外部消费者漏读带自动前缀的正文；Studio 草稿属性只在最终产物剥离。自动对齐/转写结果只向 Studio 暴露毫秒端点，引擎原生秒数在适配边界转换。

打包页左栏只读汇总 TTML/STPP 问题，右栏为紧凑下载与音乐打包。稳定对象 ID、问题类型和缺失端点构成问题键；执行时复查实际格式，突出阻塞项并滚动，格式/选项/文档变化清除旧反馈。问题按钮保持原可访问名称，高亮增加图标、描边和可访问描述。

任务数据库事务禁止同项目同时活动打包。新副本通过回读并确认未取消后，在同一事务中标记旧成功记录已替换；任务记录保留，旧文件清理。启动收敛历史与未发布孤立副本；占用失败记录警告并在列表读取、后续切换及下载结束时重试。下载在切换锁内打开文件，流关闭后重试清理。旧链接返回明确 410，界面分离当前任务与最近成功产物，显示绑定修订、旧修订及未保存修改提示。

## Phase 4 管理表与控件

歌手模型以可选 `actorRef` 保存单个 actor 目标。TTML codec 完整读取歌手列表后检查目标存在；接受无命名空间 `agent` 的空 actor 节点，额外属性、子结构、多名称及名称分类明确拒绝。草稿保存、恢复及最终 TTML 都生成标准 actor 子节点，声明顺序不排序。`rename-agent` / `delete-agent` 同时维护歌词引用和 actor 引用；通用 `set-agents` 仍拒绝悬空引用。缺失/非法 type 保留在草稿，集中输出检查仅对 TTML/STPP 阻塞，并可定位歌手 type；服务端检查 actor 目标及实际 STPP 输出类型。

元数据采用原子 `rename-metadata` 和完整值数组提交，界面逐值编辑，清空删除单值/末值，打开不清洗原数据。`ManagementTable` 共享字段的 Enter/失焦、Escape 和 IME 行为，业务表分别维护本地新增草稿及稳定行身份；歌手支持五种英文 type、ID 改名、顺序交换和逐次确认删除。确认说明主行／背景的实际歌词引用与 actor 引用，取消按钮默认聚焦。

`Controls` 提供统一 SVG 图标按钮、开关/三态复选框。按钮用显式 `data-role` 选择共享主题角色，不再根据 DOM 顺序推断主按钮。单行跳过与背景使用开关，多行跳过始终为三态复选框，歌手为集合复选框。

`usePreference` 保存浏览器 UI 偏好：打轴模式全局，下载格式按稳定项目 ID/本地文件名，内嵌 LRC 格式和输入偏移按项目作用域；各键互相独立，变化即存，不进入 TTML、dirty 或历史。偏移非零可见且可归零，不恢复完成、空拍或运行状态。没有服务端偏好同步或旧数据迁移。


## 人声处理与项目声学部分

`VocalRunner` 经 Lazulite 的 DemucsSeparator 分离，服务配置固定模型/设备；任务绑定源资产，去重同项目活动任务。真实阶段只报告排队、分离、分析及终态，取消在阶段边界检查，运行阶段仍显示正在取消。服务启动将中断任务明确终结；分离已成功时保留 separated 结果，重试只执行分析。模型名称、实际 state_dict 权重哈希、配置、分析参数/代码哈希与运行库版本随产物记录。

独立 `vocals/<project>/<result>` 保存 PCM_24 FLAC、energy.npy 和 analysis.json；写入前按峰值整曲等比例衰减，记录 gain 与量化，保留模型输出帧数/采样率/声道及开头静音。能量与 core 片段从同一持久 FLAC 计算。结果注册后随项目/任务记录保留，供未采用查看、重试、撤销和旧修订读取；失败的未注册目录在任务结束或下次启动删除，项目删除处理人声及其代理。波形冷构建和播放代理各自串行去重，窗口读取不重复全曲生成；没有按每代永久另存 WAV，代理可重建。

`VocalPanel` 显示处理/失败/时间轴视图；首次处理及明确重分析成功后一次替换 analysisId/segments，不修改歌词，失败保留旧结果，冲突时保留新产物并提供明确替换。`VocalTracks` 使用窗口内区间分轨、拖动时冻结布局，松手一次提交，支持端点/平移、连续选择合并、删除和反向框选新增。新增暂停播放，遮罩隔离其他界面并限制键盘焦点，Esc/指针取消不提交。结果与当前副本分离，片段修改不跟随改写已分配歌词。

音频处理复用大纲和稳定行 ID；`MediaTransport` 通过 portal 把唯一时间轴放到主区域，底部保留播放控制。图形音源下拉位于波形左侧标签区，波形隐藏时仍可达；图形、能量、片段及歌词轨道共用 52px 标签宽度与 5px 间距，内描边不压缩绘图区。播放音源与波形/声谱图音源独立，单一 audio 元素持有绝对时间、倍率及 A/B；加载失败明确显示，不切换回其他音源。频谱缓存身份包括人声结果 ID；能量、片段、波形等可独立显隐。

`vocal-editing.ts` 供分配按钮、片段菜单和大纲独立拖放入口共用。行起点优先、仅终点次之；完全未定行取核心起止，内部已有时间却无行锚点则拒绝。正文、Ruby、对齐单元与定时音译全部已知端点同量平移，保留未知，背景独立。先校验所有端点范围，再原子解除所选行出链和全部入链，入链来源冻结当前结束时间；失败不给历史。错误经大纲与稳定对象定位反馈，低频红光尊重 reduced-motion。


## 播放跟随与共享弹层

波形和人声能量共用分桶请求窗口及前后预取。查询只保留当前窗口（`gcTime: 0`），观察器在新窗口到达前可保留上一成功窗口；只允许相同项目、音源/结果和分辨率复用，按实际时间投影已覆盖数据，未覆盖部分留空。请求消费 AbortSignal，失败显式重试，不自动持续重试。能量按当前可见桶计算 10% 余量、向上取 0.01 倍数及最低 0.01 上限，预取区不参与显示刻度。

媒体时钟与游标继续按动画帧更新；跟随视窗以至少 32ms 间隔更新 React 状态，缓动按实际经过时间计算。波形 canvas 只在尺寸或 DPR 改变时重设设备像素尺寸，合并可见桶为一次描线；片段编号表按声学数据记忆。界面优化不写文档历史。

共享 `Select` 统一无箭头，保持原生表单值与键盘/焦点语义；可选 quotes 为“操作前缀＋歌词引用”提供分段显示，收起态和弹层一致，引用加粗，保留原文及完整标题，不插入 HTML。音译无有效偏好时默认定时，有效普通/定时记忆继续按项目或本地文件隔离；行号与目标同排，切换输出提示位于输出右侧。控件在布局阶段测量列表实际高度（含边框），按可用空间向下或向上展开；最大 280px、视口边距 8px、触发器间距 4px。空间不足时内部滚动，左右夹在视口内；滚动/窗口改变时关闭，触发器无滚动的布局位移也会关闭。弹窗中的弹层仍留在其焦点作用域内。


当前声学适配的能量取自 Lazulite `build_activity_profile()['main_rms']`，使用库的主人声提取、居中帧与 `hop_length` 时间步长，不再维护另一份 RMS 实现。该曲线未做活动曲线的时间平滑；归一化/中置修正后的 `activity`、再平滑供寻谷的 `split_activity` 不作为 Studio 能量图数据。`analyze_vocals` 不返回数组，因此分析与 profile 为两次公开接口调用。结果版本 `lazulite-vocal-core-v2-main-rms` 及源码哈希区分新产物，已有结果保持自身能量定义直到用户明确重分析。


## 人声音源与分析的独立生命周期

播放和图形音源均只提供“原曲／人声”。当前源优先选可用且匹配分离签名的人声；没有匹配项时仍可播放旧版可用人声。常规入口“分离人声”复用有效产物，不暴露强制重新分离；文件缺损提供“重新生成人声”，分离签名变化提供“更新人声分离结果”。更新仍由用户触发，替换片段遵守原子历史和并发编辑冲突规则。

分析结果保留独立能量/片段和 ID，以 audio_result_id 引用一份分离音频；复用任务读取实际返回的 analysis_id 接入，不能假定它等于 job ID。重新分析不增加音源选项，也不复制音频或重建另一份波形缓存。音源更新保留媒体位置和播放状态。audio_result_id、separation_signature、audio_sha256 必填，首次分离显式引用自身；不支持旧结构默认值或启动迁移。启动只清理未注册临时目录；新结构的历史分析和不同音频内容保留至项目删除。旧结构开发项目应删除重建。

### 人声 Phase 4 显示布局

时间轴根节点持有共享布局变量：相邻轨道 4px、分层 22px、色块 20px 与顶部 1px。标尺和波形成组，人声组内与组外使用同一间距；歌词轨道包装使用 display:contents，隐藏后不占空行。变量定义于实际绘图区，兼顾音频主栏 portal 与展开底栏。图形音源在波形行垂直居中，普通标签按共享下拉的 1px 边框与 8px 内边距内缩文字；片段保持棕色语义及独立选中、焦点反馈。

声谱图由 `spectrum-palette.ts` 提供固定 256 级显示查找表，从近黑深紫经紫红、橙色到浅黄。各整数强度的相对亮度严格递增，主题不改变数据颜色；FFT、强度范围、PCM 请求、缓存及加载/失败呈现继续由原实现负责，不进行视窗动态归一化。

日文读音服务固定使用 Sudachi C＋一致 A 细分＋精确词典分段，前端先锚点再投影原词；完整分析片段不因跨用户词边界而提前丢弃。Ruby 同行跨词及选中组移动复用原子命令和拖动预览，保留独立端点、不隐式重新打轴；跨行（含主行与背景）由命令和界面共同拒绝。

### 背景附属内容与时间轴指示线

背景独立保存 agentRefs，翻译／音译使用各自全局轨道引用背景稳定 ID；空歌手表示未指定。关系建立／改绑／解除保留附属内容和歌手，结构重排／复制／删除保留父背景成组规则；时间平移只处理明确传入的行集合，不隐式扩展背景。属性歌手使用实际选择行，不因结构成组扩散；背景编辑、音译转移、罗马字生成、音译转 Ruby 和预览读取自身内容。

TTML 背景 span 写独立 ttm:agent；翻译统一写入头部 translations/translation，按所属主行 text for 与 x-bg 保存背景。音译统一在头部按所属主行 text for 嵌入 x-bg，主／背景相邻内容合在同一 text，只有背景时不伪造主行内容；保留多轨、多内容顺序及普通／定时形态。导入识别正文与头部附属内容后才解析背景词，去掉背景正文／音译最外层装饰括号；草稿保存内容 kind、ID 与空端点。其他消费者可能裁空白、丢独立背景歌手或按主行布置背景，这不影响 Studio 自身数据。

MediaTransport 通过唯一时钟写宿主 CSS 变量，同帧投影波形、能量、实际声谱图的 2px 主题播放线；片段无播放线。TimelineIndicators 共用临时候选，在所有已显示时间绘图区及标尺画虚线；不覆盖标签、工具和声谱图说明。歌词与片段共用时间换算／吸附基础，保留各自领域约束与片段双端吸附、组边界。候选驱动色块预览、参考线及提交；非法候选显示红线和独立错误提示，不提供媒体重试。Esc、cancel、捕获丢失、源数据／视窗改变、源隐藏和卸载均清理预览，取消不入历史。底栏维持原有图层集合，能量／片段仍仅在音频处理主界面提供。


### 共有选择与逐字翻译

`editor/SelectionContext` 是画布、大纲、时间轴、人声片段的唯一有效选择，保留同类 ID 集合、稳定范围锚点和活动对象；片段选择与歌词选择互斥。展开行集合独立保存。`selection-targets` 按实际所属行／词／内容解析对象，不用父行高亮代替子对象选择。复制、剪切、删除、属性、打轴和循环读取该选择；不支持的组合禁用，操作一次入历史。翻译输入焦点清空有效歌词选择，避免沿用旧对象打轴。循环选区捕获完整对象的 min/max 包络（包括间隙），缺失／非法／超媒体边界则拒绝；后续选择不追随改写 A/B。

`timeline-editing` 支持定时音译单元平移／端点修改，跨内容按真实归属一次处理，不修改来源词／Ruby；链接冲突拒绝，预览与提交消费同一候选。歌词和片段互相提供真实端点，即使源图层隐藏；自吸附按对象身份排除，不能按相同时间值排除其他对象。

翻译采用文档级 `translationTracks`，轨道持有稳定 ID、语言、subtitle／replacement 类型（内部字段 purpose）与内容顺序；内容按主／背景行 ID 关联，保留 plain 文本或 timed 单元，空白及空轨道不丢失。草稿保存编辑身份，最终 TTML 只保留语义分组，不携带 Studio ID。正文行内 x-translation 导入为独立轨道，不按语言或位置猜测合轨；头部按外部显式分组读取，输出只写头部一次。外部 AMLL 只读翻译投影可能丢失多轨、用途及独立时间，不是 Studio 存储模型。

`timeline-projection.ts` 为恰好一端未定对象计算临时端点，先约束真实后代边界，再按行→词→Ruby传播显示边界，独立音译不强制纳入正文。两端未知或没有合法候选不显示，歌曲边缘允许零长度抓取点。只有布局和命中读取投影；真实时间负责输出、播放、循环和吸附。临时侧带虚线与可访问说明；拖动只提交指定端点，禁止不完整目标平移，不补齐未知祖先，取消与撤销保持原 null。

上方设置中的假名高亮保存全局本地集合，默认はへを，平／片假名归一化匹配实际源读音，生成窗口读偏好快照。提示不判断词性、不修改读音、不阻止应用；手改不会清除源命中，模式切换沿用既有重新生成规则。

`PackagingPanel` 主动“歌词校验”执行实际内存序列化和发布歌词检查，结果按对象与严重度去重、合并影响格式，仅列实际异常与输出阻塞。未执行及文档改变后不显示通过；下载仍独立检查最新文档。标点播放投影保留无时间／零时长文字，真实时间核对继续报告异常，各格式按自身门控拒绝，不自动制造时长。

`format-description.ts` 在下载的可展开格式说明中按当前文档和所选格式汇总表达差异，不计为校验问题；描述 Studio 导出行为，ASS 翻译普通字幕与整行音译投影分别说明。校验按钮使用共享 primary。

`TranslationTrackDialog` 的正文／翻译各截取前五个字素簇，正文级字号、独立元素及字重区分；悬停或内容复选框聚焦时展示全文。删除立即更新本地草案、清除相关选择和目标，取消丢弃整窗草案，应用沿用一次历史。全局与本轨全选复用 BooleanField 的原生三态和禁用能力，选择稳定内容 ID。归轨按原轨道／内容顺序追加，仅删除本次从非空搬至空的源轨道；无关空轨、目标及幸存 ID 保留。

## 反向注音生成的问题与定位

`rubyGenerationIssues` 一次收集带类型、严重程度、行／源 key、目标组及提案位置的问题；预检查和 `rubyGenerationCommand` 共用阻塞判断，实际提交仍验证源文档身份。人工有效读音优先于旧转换说明；完整目标组在处理跳过前比较 NFC 及统一平／片假名的读音，差异仅核对，默认跳过仍要求原输出假名种类一致。

`RubyGenerationDialog` 采用两行固定列、共享引用下拉和细分隔线。红色虚线只表示需留意；无效控件另有 aria-invalid 和说明关联。源区悬停／焦点显示浮层、Esc 先关闭浮层。内容底部 inline 问题定位与固定次要巡查按钮共用问题对象；巡查保存稳定身份和原位置，修正／跳过后向后继续。超过 80 项按约 70px 估算并测量，定位先按索引挂载／测量再处理内外层滚动与聚焦；编辑中的单元额外保持挂载。

## 手动结构编辑

`LineSplitDialog` 在原词间用可切换按钮选择多切点，长行换行展示，键盘与鼠标共用操作。领域 `previewLineSplit` 同时用于预览与原子提交校验，各结果段与词／Ruby 合并共用已知端点包络（包括首末段），不继承原行起止。包络改变链接边界时解除受影响链接，冻结其他行现有结束，保持一次历史。附属内容以结果段首词标识归属，默认翻译／音译归首段、背景归末段，删除归属段明确阻塞并要求重选；真实内容及端点不拆分。

右键已选词／Ruby 保留完整选区及范围锚点；多选“合并”和单选“合并前一项”使用相同领域规划，禁用项显示实际原因。成功选择新对象并通过 `LyricList` 挂载定位后聚焦正文或读音输入。合词保留各 Ruby 单元及时间，合 Ruby 则成为一个读音包络。

行末加号、行菜单添加词、词菜单前／后插词共用 `InlineDraft`。工作区保存插入锚点，前／后插使用右键对象；草稿组件持有文字、IME 和提交去重状态。菜单先关闭，虚拟列表定位并聚焦草稿；非空原文提交才生成一个未定时词，失败保留草稿与说明。成功后焦点交给新词正文；Enter／失焦、Esc／空输入取消不写额外历史。音译新增复用同一草稿组件。

## 时间轴画布与词级内容属性

对象拖动保持原文档排布，逐帧测量当前可见 DOM，浮动副本与 fixed 插入线表达去向；候选经现有领域命令验证，松手一次提交。没有预览重排、FLIP 或 Ruby 宽高锁定。浮动副本保留源对象的类名，overlay 样式必须以更高优先级覆盖源对象定位，避免 syncWord 的 relative 使副本参与页面排布。歌词列表及允许的大纲支持边缘停留后的距离／时间渐进滚动。

SyncLine 用左侧统一行号栏和正文／读音／SVG 标记三层布局；普通展示禁选，输入恢复原生文字选择。行末 primary 加号位于正文层。属性栏按有效对象挂载对应控件，词／Ruby 不再挂载父行表单。父组件回传与共享选区一致的行 ID 不触发自动定位，显式大纲／校验定位和模式返回仍保留。

词级 `obscene` 由单次领域命令修改，只在单词属性栏提供开关，Ruby 没有独立标记。草稿与正式 TTML 使用词 span／Ruby container 上的 `amll:obscene`，服务保存保留并校验 true／false 和词级位置。结构剪贴、合词逻辑或和原有分词门控保持。既有歌词／项目／接口／恢复版本及数据不变。
