# S2：富文档、TTML 与本地编辑

日期：2026-09-08。状态：开发中，最终结果另记验收文档。

## 阶段边界

S2 建立能独立往返 TTML 的富文档和可逆编辑基础。本轮以本地文件工作区 `/editor` 验证，不把 S1 的 HTTP 行表摘要当作可保存的富文档。服务端项目/修订持久化与媒体在 S3 接入。

本地文件编辑入口无需服务端会话。现有 `/projects/:id/edit` 继续显示服务摘要；项目列表提供本地 TTML 工作区入口，两种数据不会互相覆盖。

## 数据与写回

保留原始 XML、命名空间、未知内容及源节点定位；领域模型保持 DOM 无关。可编辑行字段与不可变原始信息分开，序列化只修改已经证明安全的节点。未修改的原始文件可单独下载，撤销到初始状态后不产生额外 XML 改写。

编辑范围先限于普通文本行的正文、行起止时间。不支持安全重映射的 Ruby/混合文本、内嵌时间或未知语义按字段只读并说明原因。保留不等于当前可编辑；不同歌手的重叠时间合法。

未定时间为 null，与零区分。草稿 TTML 使用明确的 Studio 扩展标记保存未定起止，重新导入恢复相同状态；最终 TTML 下载检查完整时间与 profile，不能将未定时间默认为零。

## 编辑与恢复

一个“应用修改”操作对应一次事务，批量命令先验证再应用。撤销/重做恢复内容、时间、ID 和相关状态；保留最近 20 步，禁止让长期会话历史无限增长。

本地检查点使用 IndexedDB 保存编辑状态及有界历史，刷新后由用户选择恢复或丢弃。保存成功只表示当前浏览器的检查点已写入，不表示服务器已保存。写入失败保持当前工作文档并显示错误。

导入失败不替换当前文档。存在未应用表单或未保存更改时，更换文档、切换行和离开工作区应避免静默丢稿。输入框与 IME 保留自身文本编辑快捷键；工作区撤销快捷键不抢占它们。

## 界面与验证

延续 S1 的紧凑工具栏、行表、属性栏与蓝色选择反馈；窄屏通过面板切换查看行表、属性和诊断。明确标注本地编辑、可编辑字段、只读原因、检查点保存状态。

必要验收包括：复杂 XML 保真往返、修改普通行时保留相邻 Ruby/扩展、未知语义只读、原子命令与撤销/重做、空时间草稿重开、本地检查点恢复及存储失败。保留少量跨模块和浏览器测试，不为占位功能增加测试。
