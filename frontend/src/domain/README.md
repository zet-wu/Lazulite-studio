# Domain：歌词编辑规则

`project-document.ts` 是唯一项目状态与 256 次历史，包含 lyrics、acoustics、editing、amll 与 lineOrder；`lyric-document.ts` 定义歌词部分：行 → 词块 → Ruby 读音单元，以及文档级有序音译／翻译轨道。音译轨道按主行或背景行的稳定 ID 引用正文，单元有独立文本和时间。翻译轨道统一保存语言／类型（内部 purpose）及有序普通或定时内容，按行 ID 关联；行另存背景关联和 agent；词保存正文、可选显式 agentRefs 与 Ruby 自身时间，不保存关联对齐单元。时间为绝对整数毫秒或 `null`，正文由词序列投影，不另存一份可写整行文本。

`lyric-commands.ts` 提供纯函数歌词编辑事务；运行时由项目层统一记录历史，不使用嵌套歌词历史。词和读音使用稳定 ID；拆分位置使用 Unicode code point，并验证 grapheme 边界。带 Ruby 或未分配附属属性的词不能猜测式拆分。命令批次只产生一次历史记录。

`segmentation.ts` 保留原文、词时间端点和空白，全文应用由单次遍历的 `segment-words` 命令完成。`batch-editing.ts` 实现范围时间偏移、CJK 词边界平滑、行时间同步和词内替换。行尾链接仅保存目标，解除及删除目标保留当前有效结束时间，草稿 TTML 带 Studio 命名空间标记；最终交换文件不带链接编辑状态。

`sync-editing.ts` 处理连续打轴游标和单次落点事务，`timeline-editing.ts` 处理行/词/Ruby 的平移与边界修改；`bpm.ts` 根据峰值估算节拍，`spectrogram.ts` 在 Worker 中计算按需片段。`preview-adapter.ts` 投影可播放内容给 AMLL；独立零时长标点保留端点，无端点纯标点仅在播放投影中借相邻词时间，不修改草稿或 Ruby 结构。

XML、HTTP、播放和 IndexedDB 均在领域层之外。TTML 导入和当前版本草稿序列化由 `adapters/ttml/lyric-codec.ts` 实现；最终交换文件不包含 Studio 草稿属性与编辑元数据，主行和背景行的稳定 ID 作为 XML 身份保留。旧开发检查点不会自动迁移。音译附属行 UI 与显式 Ruby 生成已接入。背景建立/改绑复用 `set-background-of`，由命令保持父引用、内容归属及各单元自身时间合法性，允许父背景独立绝对时间，拆行归属同样不做父子包含校验。

`pack-intervals.ts` 仅派生时间轴子轨布局，不写入歌词文档或历史；端点相接可复用子轨。

Ruby提案仅在最大重叠>50ms时滤除其他≤50ms边缘候选；全部短候选仍人工分配。defaultRubySkips按目标词全组转换读音与正文作NFC比较，只派生平/片假名相同默认跳过，不改命令或源音译。词/Ruby自身时间合法性和无损内容约束继续保留。

rubyGenerationCommand 直接返回单个 batch，不再接收时间扩展同意开关或输出仅供预览使用的扩展明细。源实际时间不变；必要的词/行包络扩展与 Ruby 设置在同一事务中。没有生成项则拒绝空操作，覆盖、未分配、读音与文档过期、行尾链接检查继续生效。

Phase 6：Ruby源在建立提案时过滤空及纯空白单元，不修改源或参与包络计算。`sublyrics.ts` 校验语言标签。`translation-editing.ts` 校验轨道、行引用、内容／单元身份与真实时间；显式归轨保留目标已有内容并按源顺序追加，仅清理本次实际搬空的源轨道，目标及无关空轨不变。set-translation-tracks 检查源轨道快照，无变化不增加历史。默认快捷拆分复用现有分词及时间分配，空白为独立分片，不并入相邻词；预览适配按原顺序保留独立纯空白词为0–0 AMLL word，不修改保存内容。多歌手仍为有序agentRefs，AMLL只按包含主唱与否派生isDuet。

`line-structure.ts`共享拆合行实际阻塞条件，使用当前Lx标识；正常链接自动继承，外部入链仅同开始时间安全改绑。翻译按稳定内容 ID 分配，正文、音译、背景和链接同一事务。

`romanization-generation.ts`将行内假名序列按源已有Ruby/正文单元边界生成ja-Latn。上下文只影响拼写，不合并单元或时间；促音、拆开拗音ky/ya、行内长音与未知隔断保留源归属，未定端点原样复制。源空白保留，真实分隔空格附着源单元，空转换占位。普通结果只存行文字/提示，定时结果存每个源归属/原时间/文字/提示。prepare只检查源快照与目标，应用当前人工结果而不重跑转换；一次batch、不改正文/Ruby、已有内容默认保留及明确局部替换。提示不写TTML，未定时生成草稿与最终定时导出校验分离。

`vocal-editing.ts` 处理片段增改删/连续合并与四类行时间分配；所有实际移动端点先验证范围，再原子冻结入链、解除出链并平移。未定端点保持未定，背景独立。片段及采用引用都进入项目历史，音频文件与大型分析数组不进入历史。

`japanese-ruby.ts` 用 code point 范围和字素边界映射整行读音；送假名锚点仅在对应唯一时拆分。提案允许完整读音修改，应用保留已有正文词边界、空白及文字；只有有效结果所需边界落入实际文档。拆词时间按 code point 长度比例舍入，空拍全部归第一词，obscene 标记复制到拆分后各块。新 Ruby 复用音拍拆分/时间分配，改动已有 Ruby 使用其已知端点包络，未改或清空保留原值。源引用变化、非法范围或倒置包络整体拒绝，单个 replace-document 进入既有项目历史。

`japanese-ruby.ts` 先对完整分析片段做唯一假名锚点，再按 code point/字素边界投影现有正文词。相邻已知汉字分段在同一原词内合成完整输入，不强制逐字拆词；无可靠跨词对应继续留空。`move-ruby` 是同行移动原子命令，接受目标词和同源单元组，保留 ID/文字/时间、拒绝跨歌词行，原位返回原文档不写历史。

背景翻译由全局翻译轨道按背景行 ID 关联，背景行直接保存有序歌手引用，空列表表示未指定，按父行解释。建立／改绑保留显式歌手；解除关系将继承的有效歌手写入新主行，同时保留附属内容；父行时间移动、删除、拆分归属及行组剪贴保持背景稳定关联，音译随对应行 ID 处理。罗马字生成与音译转 Ruby 读取目标行自己的源单元和时间；预览按实际行引用派生 isDuet，AMLL 消费侧布局不作为存储语义。

`timelineDelta` 与 `snapTimelineTime` 是歌词／片段拖动共用的位移及吸附基础。歌词候选通过既有 move/resize 规则校验，片段保留双端择近和组边界限制；各手势只保存一份候选，预览和提交共用。

`timeline-projection.ts` 只计算恰好一端未定对象的显示副本。真实后代边界约束候选，按行→词→Ruby计算；同级只借真实值，音译独立。词级候选按同行内容顺序查找，跳过两端未定的纯空白词（含连续空白）；有任一真实端点的空白和非空白词仍作为相邻边界，不跨行、不修改原词结构。媒体时长未知不借视窗结束，两端未知或无合法候选不显示。移动拒绝不完整目标，resize 只设置指定端点，不补未知祖先；显示副本不参与吸附、循环、播放或保存。

反向生成源过滤空、纯空白及明确枚举的纯标点，保留长音、连字符、撇号、迭代标记、数字和未知／混合文字。`rubyGenerationIssues` 共用预检查与提交阻塞规则；`nextRubyIssue` 以稳定问题身份、源位置及类型顺序进行循环巡查。假名差异比较完整组的当前有效读音，NFC 后统一平／片假名，仅生成非阻塞核对，不扩大默认跳过。

`merge-words`／`merge-ruby` 接收完整 ID 数组，从当前文档解析真实归属并校验连续性；单选合并前项与多选共用 `planWordMerge`／`planRubyMerge`。时间逐端点取已知最小开始／最大结束，非法包络或父子约束整体拒绝。正文合并原样拼接、保留首词 ID／空拍、脏话逻辑或，Ruby 列表及端点逐项保留；Ruby 合并保留首 ID 并移除内部时间切点。无正文子词映射。

`split-line` 接收多个原词边界、新行 ID 及每份翻译／音译／背景的目标段。`previewLineSplit` 共享预览与提交边界：所有段按词的已知开始最小值／已知结束最大值取包络，某侧全未定才保持 null，不借原行或 Ruby 时间。首段保留行 ID；边界不变的入链／末段出链继续保留，边界改变时解除受影响链接并冻结其他行的现有结束；附属内容整体改归属，独立时间不变。所有结构变更一次原子提交。

AMLL Phase 0：`amll-compatibility.ts` 统一五项检查和行／词有效歌手解释；`ProjectDocument.amll` 与 `lineOrder` 随项目历史维护。正文允许多个背景，排布独立于 TTML 顺序；批量多背景处理保留序列首条，其余转主行。词级 `agentRefs` 缺字段继承、有字段覆盖，同值显式指定不折叠。结构命令在保真后检查项目限制，无法保留有效歌手时拒绝。
