# Domain：项目与歌词规则

`project-document.ts` 持有唯一 ProjectDocument 与 256 次历史，统一 lyrics、editing、acoustics、amll、lineOrder 和 karaoke。`lyric-document.ts` 定义行、词、Ruby、有序翻译／音译轨道、歌手及元数据。时间为整数毫秒或 null，正文由词序列拼接；所有对象以稳定 ID 关联。

## 命令与结构

`lyric-commands.ts` 提供纯函数歌词事务，项目层提交一次历史。拆分使用 code point 坐标并校验字素边界。`line-structure.ts` 提供拆行入口校验：各结果段取词的已知端点包络，附属内容按选择整体归属；链接边界改变时解除相关链接并冻结现有结束时间。

词合并保留首 ID、原样拼接正文、保留 Ruby 单元和端点；Ruby 合并保留首 ID 并取时间包络。歌手有效值必须可保真。行／词复制重映射附属对象身份，背景和附属内容保持稳定归属。

`segmentation.ts` 按原文边界分词并分配已有时间，空白作为独立片段。`batch-editing.ts` 管范围偏移、边界平滑和词内替换。`translation-editing.ts` 管轨道、语言、用途、普通／定时内容和显式归轨，源快照变化时拒绝提交。

## 时间与选择

`sync-editing.ts` 提供连续／本行打轴游标与落点，空拍、忽略及行尾链接由项目 editing 保存。`timeline-editing.ts` 管实际端点与平移，`timelineDelta`／`snapTimelineTime` 为歌词与声学片段共享换算和吸附。`pack-intervals.ts` 按区间派生子轨。

`timeline-projection.ts` 为单端未知对象计算抓取用显示副本，按真实后代和相邻端点约束，再逐层传播。保存、播放、循环与输出读取真实时间，resize 只提交操作端点。

`vocal-editing.ts` 管片段增删改、连续合并与歌词时间分配，所有端点校验后原子平移并处理链接。背景按明确传入的行集合处理。`alignment.ts` 核对全局结果范围、采用合法建议、按选项清空缺失端与合并连续片段覆盖的行内短空隙，再重算包络并提交一次事务。

## 日文生成

`japanese-ruby.ts` 用完整读音范围的唯一假名锚点保留词内最细可靠分段，默认保留原词间边界。显式自动合并只投影可靠且不可拆的连续汉字范围，不跨已有 Ruby／空白／标点／行；提案源词区间仅存在于窗口计算。提案构造和重试合并维持原文覆盖，不可变正文范围与可编辑读音分开；应用核对源快照身份，仅为非空读音拆分或合并，复用 `planWordMerge` 的首 ID、时间包络、歌手和屏蔽规则。项目事务统一转接首词空拍、清理失效导唱并保留有效链接，一次历史保存全部变化。新 Ruby 按音拍分配时间，未改读音保留原单元，修改已有读音使用原 Ruby 时间包络。`move-ruby` 以同行同源选中组移动，保留 ID、读音与时间。

`romanization-generation.ts` 按行内上下文生成 ja-Latn，源单元及端点归属保持；促音、拗音、长音和未知读音隔断共同决定拼写。用户可修改普通／定时结果，应用使用当前提案及目标快照。

反向 Ruby 生成使用音译时间重叠与人工归组。最大重叠超过 50 ms 时滤除其他小于等于 50 ms 的候选；空白及明确枚举的纯标点在提案边界过滤。假名核对、默认跳过与人工覆盖各自保留语义，必要包络扩展和 Ruby 设置组成一个 batch。

## 兼容与卡拉 OK

`amll-compatibility.ts` 定义五项限制、有效歌手和显示排布。词级显式歌手覆盖所属行，背景可继承主行；兼容批量转换经项目命令校验。`preview-adapter.ts` 为 AMLL 派生可播放投影与歌手侧，保留源文档。

`karaoke.ts` 管三类稳定锚点导唱、组、默认文字、阈值与文件选择。`singer-markers.ts` 以实际有效歌手集合绑定触发串和图片声明。结构事务维护锚点邻接与关联删除，显式整行平移同步所属导唱；范围问题作为待修复输出问题保留。

## 显式选区与附属结构

`selection-editing.ts` 定义共享对象选区与成组移动、附属内容／单元合并、空拍和读音批量操作规则。正文词、Ruby、附属单元按已知端点取包络；附属内容行合并保留内部单元。普通与定时内容不能混合合并，连续性依真实对象顺序判断。

`merge-lines` 接收完整连续主行 ID 集合，一次串接正文并迁移各轨道内容和背景。行开始取首个已知开始，结束取末个已知结束；跳过对齐取全部参与行均开启，忽略打轴保留首行状态。歌手、段落、卡拉 OK 分组分别继承首个有效非空值。只继承区域外到首行的入链和末行到区域外的出链，移除内部边界链接并冻结外部来源行当前结束。首行行前导唱保留，后续行前导唱删除，词／Ruby 导唱通过稳定锚点迁移。兼容限制在项目事务提交前校验。

批量替换仅在单个正文词或 Ruby 内做字面量匹配，非空修改保留附属属性；空字符串删除对象及关联空拍／失效导唱，真实空白保留。清除注音沿用非偏移批处理范围，清除导唱仅使用明确的行集合。`set-song-part` 一次设置明确选中的主行自由标签，空字符串和纯空白为 null，实质内容保留原字符串。

分组命令以原 ID 到最终 ID 的映射区别重命名与真实删除，原子维护行归属及三类输出键。删除将成员置空；协调时只给没有记录的新行分配标准组，并比较事务前后背景关系同步标准角色。拆分与富文本整行复制携带源分组，已有空归属保持。项目允许零组，输出门控由适配器执行。

歌手 `skip` 是项目 v9 的必需布尔字段，默认关闭。形状检查与启用参数检查分别执行；跳过仍保留全部参数及源歌手引用。

项目 v9 的 `karaoke.offsets` 以输出 ID 保存整数毫秒；`offsets` 命令一次提交完整合法值，关联分组重命名原子迁移，歌词结构协调清理已删除轨道的输出设置。
