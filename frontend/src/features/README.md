# Features：工作区与用户操作

`Workspace` 组合项目连接、保存／恢复、资源查询及模型任务。`editor/EditorWorkspace` 组合获取、音频处理、编辑、打轴、AMLL 预览、卡拉 OK 和打包，共享项目历史、草稿与媒体。

## 画布与操作

`LyricList`、`SyncLine`、大纲和属性栏使用 `SelectionContext` 的唯一有效选择；虚拟列表保持活动输入挂载，显式定位在挂载和真实测量后滚动。选区命令通过 `editing-actions.ts` 组合领域事务，纯文本输入保留原生选区与 IME 行为。

`object-drag.ts` 管指针捕获、源副本、插入线、边缘滚动与取消。候选使用领域命令验证，释放时一次提交。`InlineDraft` 管新增文字、Enter／失焦去重与取消。管理弹窗保存局部提案，应用进入项目历史。

`SyncPanel` 从当前选择派生打轴游标，使用媒体时钟落点；`TimelineTracks` 显示时间区间并提交拖动事务。`KaraokeTools` 管分组、歌手标记、自动插入及输出选择，`KaraokeTrack` 复用共享时间视窗。正文与 Ruby 导唱使用共同文字行与 Green／Jade 语义配色。

## 媒体与计算

`MediaTransport` 维护唯一播放器、速度、A/B、视窗和播放跟随，音频页通过 portal 将时间轴放入主区。原曲／人声的播放与图形选源独立；窗口请求取消过期工作，频谱 Worker 按音源生命周期释放。

`VocalPanel` 组合分离／重分析任务与原子接入，`VocalTracks` 编辑当前项目片段；任务产物和用户片段副本各有生命周期。全局对齐捕获修订与参数，运行期间锁定编辑，成功后由当前页面有效意图一次应用与保存。

日文注音、罗马字和反向 Ruby 窗口展示绑定源快照的可编辑提案，应用前校验范围与来源。反馈与任务运行共用 MessageBar；业务独立持有任务状态与各来源事件，通过 AudioReviewContext 的任务／消息 Portal 挂载到头部下方、模式导航上方。运行行无关闭入口，阶段和实际设备原位更新，取消等待终态；连接／取消失败保留已知状态和对齐编辑锁。结果事件的操作按任务 ID 绑定，关闭后轮询不重发，可从音频工具重新查看。人声结果替换决策保留在结果区域，有旧片段时运行或错误消息不遮掉时间轴。

## 获取与输出

`LyricAcquisition` 组合本地、内嵌及四源候选；搜索条件、取消、排序和有界全文缓存由获取状态管理。候选预览经明确选择后一次导入。

`PackagingPanel` 组合格式说明、普通／AMLL 校验、下载和音乐打包。问题树按稳定对象定位，`useAutomaticValidation` 绑定项目及实际输入，按批次让出主线程；执行下载或打包时再次检查捕获快照。保存失败、冲突和发布结果以各自状态呈现。

UI 偏好、快捷键、侧栏尺寸和显示开关通过服务端 settings 保存。项目编辑配置通过领域命令保存；播放与选择更新只影响界面状态。

## 共享歌词动作与段落

画布与时间轴经 `SelectionContext.commands.openContext` 使用同一菜单。菜单以稳定动作标识组合领域选区操作，并使用实际项目事务预检资格与禁用说明；所有合并都要求显式选择至少两个连续对象。翻译与音译复用附属选区形状，以 `attachment` 区分轨道集合，输入框保留原生文字菜单。

`SongPartField` 在行属性中编辑自由段落标签，多值只读，显式清除后再填写；背景显示父行段落并只读。草稿保护 IME，Enter／失焦提交去重。批处理按钮使用 `aria-pressed` 和主题选中样式；七模式使用共享装饰 SVG。音频工具栏为片段与自动对齐分别提供 Portal，自动对齐容器位于 DOM 末尾并靠右。

### 对象选择与焦点恢复

`editor/selection-recovery.ts` 使用变更前的父子关系、同级顺序和活动对象，在实际新文档中计算最近的存续目标；删除、剪切及历史失效选区共用该规则。`SelectionContext` 记录画布／大纲／时间轴操作区域并传递一次焦点请求，不写入文档历史。虚拟列表先挂载目标，再以最小滚动聚焦对象容器。普通点击重设单选及范围锚点；对象拖动在阈值前保留整组，释放未拖动时才收敛，程序化聚焦只确认既有选择。

`DeviceSettings` 共用本机偏好读写，编辑器设置菜单的共享弹窗返回原位置；设置菜单独立按内容扩宽，设备偏好可在对齐锁定期间修改，仅影响后续任务。

日文注音窗口每次打开默认关闭自动合并；显式切换从源快照重建提案并丢弃未应用输入，取消或忽略旧请求，失败不回退旧模式。普通重试保留手工内容；服务失败仍可手填缺失读音后应用，源变化阻止应用。预览按状态／完整读音／正文排列，正文底部对齐；状态用 `--muted` 且参与字体测宽，完整块换行，缩放不更换输入节点。

分组管理保持局部草稿、稳定输入焦点与一次应用；删除影响提示以歌词行计数。输出组下拉区分可清空的“未选择分组”和禁用的“多个值”。歌手跳过开关禁用参数字段但保留草稿值。导唱工具使用共享 TopMenu，属性按所在行、已选数量、文字及双端时间排列；Delete／右键删除后恢复所属行焦点，正常删除只更新状态。

歌曲段落同值时直接清空提交，多值时只读并提供紧邻清除图标；清除仅作用于明确选择的主行，保留选区和输入焦点。共享 Icon／IconButton 承担保存、撤销、重做、刷新、搜索、加号及删除的可访问名称和焦点提示。

`useSearchConditions` 管理源音频标签读取、编辑版本与音源身份失效控制，读取失败保留条件。NetworkLyrics 显式填入三个字段并保存；结果保留，放大镜提交和表单 Enter 触发搜索。

`projectErrorText` 在编辑与保存错误展示边界将当前项目中可识别的内部 UUID 引用转换为行、词、轨道、内容或导唱说明，项目原始引用保持不变。
